## 启动与操作

1. 用 Unity 2022.3.53f1c1 打开项目，打开 Assets/_Project/Scenes/MainMenu.unity，进入 Play。
2. “开始游戏”和“选择关卡”都打开五关列表，可直接选关；返回或 Esc 关闭。也可在编辑器直接打开任一 OpenField 场景。
3. 点击有效空位只打开选塔框；悬停预览，点击选项或选定空位后按数字键建造。第一、二关四种塔，第三至第五关六种。布置和进攻均可建造。
4. 点击已有塔查看属性与射程；点击出售再确认。取消只关闭确认，保留选中塔；右键 / Esc 逐步取消。
5. 点击任一实际入口按钮或 Space 开整波。出怪中按钮隐藏，出怪结束且仍有下一波时可带残敌提前开波。不是只从点击的入口出怪。
6. 末波清场胜利，核心归零失败；Again 重开、Return 返回、前四关 Next 进入下一关，第五关无 Next。
7. 右上角“暂停”打开 v2 图片面板，“返回游戏”或 Esc 继续，“退出到主菜单”返回；“设置”可调总音量、静音、桌面全屏 / 窗口及恢复默认，自动保存。设置页返回或 Esc 先回到暂停菜单。“1x / 2x”切换倍率。Esc 先取消出售确认 / 当前选择，没有选择时才暂停。暂停禁止建造 / 出售 / 开波并保留 HUD，继续恢复原倍率；重开 / 换关 / 返回恢复 1x。见 [暂停说明](PAUSE_PLAYBACK.md)、[设置说明](SETTINGS.md)。

## 手动验收重点

- 五关入口数分别 1 / 2 / 2 / 2 / 3；核心、入口、组织岛和膜边与逻辑格近似对齐，敌人不穿固定障碍，壁垒存活时在其接敌位置停下，塔不压边缘。
- 所有可建单位不改路。壁垒 30 ATP / 500 生命，拦截全部经过敌人；可建超过 6 座，破裂或出售后可补建，无累计额度或封路提示。
- 普通容量 1、巨噬 2；普通细胞满额单位继续通过，壁垒不因人数溢出。阵亡 / 出售释放接敌和占用，可补建；死亡不退款。
- 购塔仅成功扣费一次；25 ATP 塔出售返 12。取消、重复确认、塔死亡和同格替换不误售 / 重复退款。
- 采样连线、抗体记忆 / 标记、巨噬吞噬与消化、减速、酸区、神经连锁反馈可辨识。Boss 预告、护盾、抗原变化和召唤计入清场。
- 轮间奖励只发一次；提前开波保留旧敌人，末敌泄露归零失败优先；连续重试 / 返回 / 下一关无旧对象残留。
- 不同窗口下 HUD、菜单和入口按钮可读且不穿透地图；地图按真实视口等比完整显示，世界 Sprite / 射程不随窗口拉伸；不同窗口比例允许留空。见 [拉伸修复](VIEWPORT_ASPECT.md)。

设置内点击喇叭切换静音，拖动图片滑块调音量；静音时保留数值与蓝条，0 音量也显示静音图标。设置文字和百分比已接入像素字图。最新 [自动测试](Testing/2026-10-19_SettingsText.md)为 EditMode 109/109、PlayMode 20/20，含图片数字、保存 / 恢复默认 / 返回及美术换图、拉条对齐；不代表桌面系统全屏切换、所有窗口比例、五关完整通关或平衡已验收，也没有当前版本 Player 发布 / Profiler 收益结论。
