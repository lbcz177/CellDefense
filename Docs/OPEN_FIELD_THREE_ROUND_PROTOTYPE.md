## 目的

用一张开放地图完成三轮核心防御：玩家每轮布置免疫塔，敌人从固定感染点进入开放区域并向中央组织核心移动。现有固定路线场景保留为回归参考，主线策划已按当前玩法更新。

## 单局规则

2026-10-14 敌人更新：三关已引用 EnemyRoster01 / 02 / 03 的混合三波，包含普通菌、高速菌、重甲菌及每关一名 Boss。计划数量仍为 5 / 7 / 10、30 / 48 / 72、30 / 48 / 72；召唤另外计入活跃集合。八种独立数据与 Prefab、护盾 / 破壳 / 阶段 / 抗原变化已接入，旧单类型资产保留。新版本需用户重新导入和 Play，详细步骤见 [敌人接入验证](ENEMY_IMPLEMENTATION.md)。下文初版单类型示例作为参数沿革保留，实际阵容以新波次引用为准。

1. 地图使用可配置的格子范围。核心位于中部，边缘设置两个或三个固定感染点。除核心、感染点、固定障碍和已有建筑占用的格子外，玩家可以在任意有效格子建塔。
2. 每轮依次进入布置、进攻、结算阶段。布置阶段显示本轮资源、塔的花费、范围和放置虚影；玩家确认开始后进入进攻阶段。
3. 每关三轮。第一关从左、右、上三个入口轮流出敌，第二关从底部左右两个入口轮流出敌，第三关从左、右两个入口轮流出敌。到达核心时扣除核心生命并移除该敌人。核心生命归零则失败；第三轮出完且场上敌人全部退出、核心仍存活时胜利。暂未配置每轮不同的入口集合。
4. 首版复用已有免疫塔的自动攻击与标记、吞噬关系，不增加抽卡、城镇经营或局外成长。

## 寻路与放置

- 塔占用一个格子，敌人不能穿过被占用的格子或固定障碍。
- 从核心向外计算整张地图的距离场；每轮进攻开始时为各感染点生成一条路径，同一感染点出现的敌人共用该路径。这样现有敌人移动、瞄准和战斗代码可以直接复用。
- 放塔时先在临时占用图上检查每个感染点是否仍能到达核心。任何感染点被封死，放置预览显示无效，点击不扣资源也不创建塔。
- 持久距离场在地图初始化、占用和释放后更新；候选建造检查也会临时计算距离场。空格悬停结果缓存到鼠标移入另一格或建造改变占用；打开选择框和最终建造仍重新检查。原型使用四方向相邻格子，不处理斜穿墙角。
- 敌人进攻期间暂不允许新建或移动塔，避免移动中的敌人因地图变化失去下一格。

## 最小交付

- 独立原型场景，不改动现有两关的地图与胜负流程。通过 Unity 菜单 `Cell Defense > Create Open Field Prototype Scene` 生成场景并加入 Scenes In Build。
- 可从 Inspector 配置地图尺寸、核心位置、感染点、三轮敌人数量与资源。
- 放置预览能区分有效格、资源不足、路径被封死；有效放置扣费且阻挡敌人。
- 三轮分别手动开始进攻，清场后自动结算并返回布置；核心生命与胜负结果需在编辑器 Play 模式验证。

## 验收情形

1. 在不同位置建造相同的塔，会改变敌人经过的路线或受攻击时间。
2. 试图用塔完全封闭任一感染点时，建造被拒绝，资源和地图不变化。
3. 多个感染点轮流生成敌人，允许不同入口的敌人同时在场；所有存活敌人都能继续向核心移动。
4. 第三轮最后一名敌人死亡或到达核心后正确结算；核心生命提前归零立即失败。

## 在 Unity 中试玩

1. 等待脚本导入完成，直接打开 `Assets/_Project/Scenes/OpenFieldPrototype.unity`；第二、三关分别为 `OpenFieldLevel02.unity`、`OpenFieldLevel03.unity`。若第一关场景文件缺失，可在顶部菜单选择 `Cell Defense > Create Open Field Prototype Scene` 重新创建。
2. 按 Play，也可打开 `MainMenu` 后通过开始游戏进入。上方临时界面显示轮数、核心生命与 ATP。先点击有效空格，格子旁弹出图标、名称与 ATP 价格；悬停选项在选中格显示对应虚影和射程，点击选项完成一次建造并关闭选择框。资源不足的选项置灰，但仍可悬停看红色预览。右键、Esc、取消按钮关闭；点击另一有效空格切换建造位置。选择框内按数字键 `1–3`（第三关 `1–6`）也可建造；未选择空格时数字键不会进入直接放塔模式。
3. 按空格或点击 `Start assault` 开始进攻，同时关闭选择框。每轮结束自动返回布置阶段；第三轮结束显示原有的胜利预制体，核心生命归零显示失败预制体。`Again` 重新挑战当前关，`Return` 返回主菜单；第一关胜利 `Next` 进入第二关，第二关 `Next` 进入第三关，第三关隐藏 `Next`。
4. 地图尺寸、核心和感染点、轮间 ATP、信号范围与 Enemy Speed Multiplier 可以在控制器对象上调整；敌人数量、Spawn Interval、Burst Size 和 Burst Interval 来自引用的 WaveDefinition。

第二关当前三波为 30 / 48 / 72，只在两个底部入口轮流生成；每组 6 个，组内间隔 0.12 / 0.10 / 0.08 秒，组间间隔 2.2 / 1.9 / 1.6 秒。开局 ATP 200，轮间补给 60，核心生命 20；速度倍率 0.75，对应当前敌人每秒 1.5 世界单位。第一关保持原 5 / 7 / 10 配置和倍率 1。

第三关使用独立的 `OpenField03_Wave*.asset` 与敌人配置，波次先沿用第二关的数量、分组和速度；开局 ATP 250、轮间 60、核心生命 20。第三关敌人 Prefab 是现有敌人的独立副本，加入 EnemySlowState 与 EnemyStunState，保留既有生命、动画、标记与复用规则。第一、二关仍选择原三塔；第三关追加纤维蛋白壁垒、酸化炮、神经脉冲。新塔各自有独立 Prefab / Definition，引用已有图片与图标，不依赖运行时临时补组件。

新塔试玩价格分别为 30 / 45 / 50 ATP；减速半径 2.5、比例 40%；酸化直击 15、每秒 10 持续 3 秒、射程 3、间隔 2 秒；神经主目标 45、最多 3 目标、保留率 80%、停顿 0.2 秒、射程 3、间隔 2 秒。这是接线与试玩起点，尚无平衡和 Play 证据。酸区已补半透明绿色地面圆与边界，按实际半径显示、到期淡出，显示实例复用；神经连锁仍没有电弧 VFX。
