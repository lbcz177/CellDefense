# 第一关三轮新手引导

日期：2026-10-21；Unity 2022.3.53f1c1。仅 OpenFieldPrototype 启用。

2026-10-28 开波规则更新：第一波仍手动开启，之后每波出兵结束后等待 10 秒游戏时间自动开下一波，不要求清场；可手动提前开启。引导随真实轮次推进，可在战中建造或暂停调整，不会为等待引导操作而延长倒计时。旧建议防线的逐轮验证单独保留手动节奏，自动计时另有专项覆盖，见 [自动开波](AUTO_WAVES.md)。

## 玩家操作

进入第一关后跟随青色目标框：点击有效空格、在原建造菜单选择细胞、点入口开波。第一轮建议先建两座近卫；第二轮在火力覆盖处加壁垒；第三轮加巨噬、将近卫增援至四座并升级一次。已有塔、经济、敌人和波次规则保持原样。

提示是建议，可自由操作和提前开波；右上“跳过引导”只跳过本局，重开或再次进入第一关重新开始。壁垒说明用“知道了”继续，升级提示可点“稍后升级”。暂停时隐藏提示，恢复后继续；出售确认期间让出界面，胜负后自动隐藏。其他四关没有引导层。

## 当前步骤与边界

| 阶段 | 提示与推进 |
|---|---|
| 第一轮 | 高亮有效空格及近卫卡片，成功布置两座后指向开波按钮；不强制位置或阻止提前开波 |
| 第二轮 | 高亮路线上有效壁垒格及壁垒卡片；成功建造后介绍承伤，死亡 / 出售后回到补建提示 |
| 第三轮 | 巨噬卡片、增援近卫、已有伤害塔和升级按钮；真实升级成功或选择稍后升级后进入末波提示 |
| 跳过 / 终局 | 立即隐藏面板与目标框；不改资源、波次、倍率或结算 |

普通细胞不能吸引路线外的敌人，建议格由第一入口地形路径和有效建造格计算。近卫优先推荐路线旁空位，壁垒 / 巨噬推荐路径上的有效格。玩家仍可选其他格；推荐布局只是一套验证案例，不保证任意布局胜利。抗原协作没有扩展为第三关引导。

## 源码阅读

- FirstLevelTutorial：根据当前轮次与存活细胞快照选择步骤，订阅成功操作；不操作 EconomyService 或刷怪。
- OpenFieldPrototypeController：通过 SelectionChanged、RoundStateChanged、TowerBuilt / TowerUpgraded / TowerSold / TowerLost 发布结果；建造事件在事务提交后发布。
- 三个原菜单仅增加只读 RectTransform 查询，给目标框定位；所有按钮仍执行原业务方法。
- 提示面板采用现有字体与 UGUI，目标框为不拦截射线的四条边；面板在安全区内避让选塔菜单、属性菜单、HUD 和目标区域。无新增图片素材。
- OnDisable 取消事件与渲染回调；OnEnable 重新读取快照。每局独立，不写 PlayerPrefs。

本次保持现有数值；先验证具体建议防线，再由用户试玩判断提示是否易懂、等待是否过长以及数值是否需要修改。既有 Android APK 与商店草稿不会随源码自动更新。
