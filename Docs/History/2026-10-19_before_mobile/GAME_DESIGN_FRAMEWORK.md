## 1. 游戏目标与策略来源

玩家在开放组织地图上，用有限的纤维蛋白壁垒安排入侵通道，自由布置和保护免疫细胞，通过抗原协作、拦截、控制和范围攻击守住核心。

体验目标是调整摆法与搭配后攻克原本失败的关卡，并在后期获得聚怪清群的成长感。单关期望不超过约 20 分钟，属于待试玩验证的目标。重点决策为 ATP 的投入位置、有限壁垒的路线收益、前排保护与损失，以及采样 / 标记 / 控制 / 清群的配合。限额规则本身不能证明没有唯一最优迷宫；免疫协作也需要试玩证明不会退化为固定三塔配方。

## 3. 单局循环、开波与胜负

进入场景时为 Planning，玩家可布置并手动开第 1 波；Assault 期间也可建造和出售，战斗继续。清场后未到第 3 波则进入下一轮布置；末波出完且所有敌人 / 召唤物退出、核心仍存活时胜利。核心归零始终失败优先。

- 每个实际使用的入口显示开波按钮；点任一入口或按 Space 都开始同一整波，出怪按入口列表轮换。
- 本波仍在计划出怪时隐藏入口按钮；出怪完成且尚有下一波时，允许保留残敌提前开下一波。不会并行运行两份刷怪协程。
- 轮间 ATP 每次进入下一轮只发一次：正常清场时发，提前开波则在点击时发；没有额外提前奖励。
- 提前开波保留旧敌人、召唤物及有效路径。最后一波启动或终局隐藏开波按钮。
- 轮间保留已建塔、ATP 和核心生命；布置期默认不自动暂停，冷却、记忆和消化继续计时；玩家可手动暂停。
- 胜负提供重试 / 返回；前四关胜利可进入下一关，第五关不显示下一关。

暂停为独立于波次的状态：布置 / 战斗均可暂停；暂停时冻结游戏时间、禁止建造 / 出售 / 开波，继续恢复此前 1x / 2x。倍率换轮保留，终局、重开、换关、返回菜单与控制器禁用恢复 1x。Esc 在设置页先返回暂停菜单；否则先取消确认或当前选择，没有选择时暂停，暂停菜单内继续。暂停页使用用户 v2 图片，三个按钮均接线；右上工具条保持文字。见 [暂停与倍速](PAUSE_PLAYBACK.md)。

设置包含总音量 0–100%、保留音量的静音、桌面 Player 无边框全屏 / 窗口切换、恢复默认，并自动保存到本地。默认音量 100%、静音关闭、全屏开启；编辑器不能切换 Player 窗口，显示模式项禁用并提示。主菜单“设置”与战斗暂停页复用同一设置页和偏好，主菜单不改变时间，暂停设置返回后仍暂停；返回 / Esc 回到来源菜单。主菜单设置与选关页互斥。不含独立音乐音量。见 [设置](SETTINGS.md)。

## 4. 建造、有限改路与承伤

### 建造与路径

Planning / Assault 均可点击有效空位打开 UGUI 选塔框，悬停显示虚影和射程，点击选项扣费建造。有效格须在地图内，且不是核心、入口、固定障碍或占用格；ATP 足够，失败不扣钱或额度。仅纤维蛋白壁垒参与寻路阻挡，其余细胞占建造格但允许敌人通行。

壁垒每关累计限建 6 座，每座 30 ATP，击杀、轮间收入、换轮、出售都不恢复额度；重开或换关重置。所有入口必须可达核心。战中壁垒还不能压住敌人当前 / 下一格，且每个在场单位的下一节点必须仍可达。建造 / 出售壁垒刷新入口及在场剩余路线，保留敌人当前位置、当前路段、生命、速度、减速、拦截状态与 SpawnVersion。

没有第一波后永久锁路、绕路格数上限、完全封路或敌人动态拆壁垒规则。

### 有限拦截

普通细胞 100 生命、容量 1；巨噬 250 生命、容量 2。敌人只接战当前路线段上的细胞，按到达先后占容量；满额后通过该细胞，不因稍后空出容量而回头。普通敌人每 1 秒造成 10 伤害，Boss 25；首次伤害等待完整间隔，停顿时不出手，不补打累积连击。

细胞死亡立即禁用攻击与光环、释放建造格、信号邻接及拦截，接敌单位继续前进；无死亡退款。壁垒保留减速光环，当前不接敌承伤。路外追击、塔移动 / 撤退及动态拆墙未提供。

## 5. 经济、购买与出售

ATP 来自开局、击杀及轮间奖励，不被动恢复。普通菌 / 高速菌 / 重甲菌击杀奖励为 15 / 12 / 24，三名 Boss 为 60 / 100 / 150，召唤物为 0；以引用 EnemyDefinition 为准。跨关重新初始化经济。

点击已有塔查看属性和射程；出售先二次确认。退款为实际支付的建造费与已支付升级费之和的 50%，整数向下取整，例如 25 → 12、30 → 15。退款不受后续配置价格变化影响。布置和进攻均可出售，终局拒绝；死亡、重复确认、旧确认作用于同格新塔均不产生误售 / 重复退款。出售壁垒会更新路线，但累计额度不返还。

五关复用现有单次升级：近卫、巨噬、酸化、神经脉冲可 Lv.1 → Lv.2 一次，费用为实付建造价，伤害 +50%，保留原有 1.15 倍视觉缩放。生命 / 射程 / 攻击间隔 / 接敌 / 抗原记忆 / 当前冷却和路径不重置。抗体及壁垒暂未开放升级，不收升级费用。布置和战斗可升级，暂停 / 终局 / 死亡 / 满级 / ATP 不足时拒绝；出售按两笔实付合计退款。完整升级树、移动和主动技能尚未接入，见 [退出与升级](QUIT_AND_UPGRADE.md)。

## 6. 六塔与免疫协作

| 塔 | 费用 | 基础伤害 | 间隔 | 射程 | 基础效果 |
|---|---:|---:|---|---:|---|
| 近卫塔 | 25 | 25 | 1 秒 | 2.5 | 投射物命中采集目标当前抗原 |
| 抗体标记塔 | 40 | 0 | 1.5 秒 | 3 | 已知抗原目标命中后标记 4 秒，受伤乘 1.15 |
| 巨噬细胞 | 25 | 25 | 1 秒 | 2.5 | 普通攻击；可吞噬目标门槛 20 / 标记后 50，消化 3 秒 |
| 纤维蛋白壁垒 | 30 | 0 | 光环每 0.1 秒扫描 | 2.5 | 唯一改路塔，减速 40%，各来源取最强 |
| 溶酶体酸化炮 | 45 | 15 | 2 秒 | 3 | 命中固定酸区，每秒 10、持续 3 秒、半径 1.25，可叠加；酸伤破壳 |
| 神经脉冲刺突 | 50 | 45 | 2 秒 | 3 | 最多三目标，45 / 36 / 28.8，连锁半径 2.5、停顿 0.2 秒 |

近卫命中 → 半径 3 格内一跳已建邻居共享 → 抗体记忆该类别 8 秒 → 标记对应敌人 → 统一伤害链应用一次 15% 易伤 → 巨噬使用提高后的吞噬门槛。没有多跳中继或全图共享。

抗体只从已知抗原且标记组件有效的目标中选择前排；没有候选不耗冷却。主动攻击每次按剩余实际路径最短优先，策略优先级只处理并列。动画前摇保留承诺目标，释放验证版本和有效性，不临时换人。近卫采样连线、抗体记忆环和神经连锁路径已有反馈。

重复标记刷新时限，不叠加增伤；回池重置状态。巨噬不能吞噬 Boss、有护盾或配置免疫目标。机制是科学启发的玩法改编，不作为医学模拟。

## 7. 敌人、Boss 与波次

八种独立单位包括葡萄球菌群、鞭毛双球菌、重甲芽孢杆菌、真菌孢子、病毒复制体，以及真菌、生物膜核心、病毒母体三名 Boss。普通菌 / 高速菌 / 重甲菌生命 100 / 55 / 240，基础速度 2 / 3.2 / 1.2；Boss 生命 800 / 1400 / 2000。

- 重甲外壳减伤 25%，酸伤先破壳再结算，破壳 3 秒。
- 真菌按阶段有限播散，共最多 6 个孢子，并在后段加速。
- 生物膜核心提供自身 / 附近有限目标护盾和治疗；这是 Boss 能力，不代表群落 / 生物膜全局系统已经实现。
- 病毒母体最多召唤 8 个复制体，阶段中一次换抗原；旧抗原子弹不会误标记变异目标。
- 召唤物继承母体当前路径进度，单独计入清场；母体退出不会自动清掉既有召唤物。
- Boss 减速 / 停顿效果系数 0.5，控制恢复窗口按配置；Boss 不可吞噬。
- 第二关分组为每组 6，三轮组内间隔 0.12 / 0.10 / 0.08 秒，组间 2.2 / 1.9 / 1.6 秒。第三关末轮保留病毒母体并在末尾追加真菌；第四、五关复用。

敌人泄露扣各自配置生命，普通 / 高速 1、重甲 2、Boss 5 / 6 / 8；召唤物 1。旧设计过程见 [敌人设计记录](ENEMY_DESIGN.md)，当前接口见 [实现记录](ENEMY_IMPLEMENTATION.md)。

## 8. 表现与操作

当前使用 UGUI：图片 HUD 场景预制体、空位选塔、已有塔属性 / 确认出售、入口按钮和敌人状态；胜负复用原预制体。旧英文 IMGUI 状态栏已移除。右键 / Esc 关闭选择或取消出售确认，选定空位后可用数字键选择对应塔。

完整 15×11 棋盘通过正交相机铺满 Game 视口，允许非等比拉伸；背景、单位、路径、射程和输入共用映射，屏幕 UI 图案保持比例。没有强制 Windows 全屏。图像和逻辑障碍独立，仍需目视检查。
