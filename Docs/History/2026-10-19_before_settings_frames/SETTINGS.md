# 设置

日期：2026-10-19；适用五个 OpenField 关卡，优先桌面独立运行。

## 操作

暂停菜单 → 设置。调整即时生效并自动保存，不需要额外点击应用。返回按钮或 Esc 回到暂停菜单，再点返回游戏 / Esc 继续；保持原有 1x / 2x。

| 项目 | 行为 | 默认值 |
|---|---|---|
| 总音量 | 0–100%，控制 AudioListener 总输出，覆盖当前战斗音效 | 100% |
| 静音 | 点击喇叭切换；输出置零，保留滑块音量；取消后恢复该音量；静音时拖动滑块不会自动解除静音 | 关闭 |
| 全屏 | 勾选为无边框全屏，取消为窗口模式；仅桌面 Player 可操作 | 开启 |
| 恢复默认 | 恢复上述三项并立即保存 | — |

编辑器中全屏项禁用并显示“全屏切换在独立运行时生效”，避免把 Game 视图操作描述为独立窗口切换。目前没有背景音乐资产，因此没有单独的音乐音量项。主菜单尚未增加设置入口。

## 代码与保存

- `GameSettings` 在首场景加载前读取 PlayerPrefs，并应用音频和支持平台的显示模式。所有场景共享同一实例，不依赖暂停 UI 存活，不改变 Time.timeScale。
- 保存键前缀为 `CellDefense.Settings.v1`，含 `.Volume`、`.Muted`、`.Fullscreen`；修改 / 恢复默认后调用 PlayerPrefs.Save。音量限制 0–1；非有限数回退为 1。
- `GameSettingsPanel` 使用现有空面板、声音与拉条五图，以及新绘制的设置文字图片；全屏开关和返回 / 默认按钮背景仍使用现有控件。设置页不再叠加 TMP 文字，其他界面的字体引用保留。原图及 .meta 保留。
- `OpenFieldPlaybackControls` 管理暂停菜单和设置页的互斥显示；`HandleEscape` 优先关闭设置。恢复、终局、退出和禁用均清除设置页显示状态，下次暂停仍从暂停菜单进入。

设置页与暂停共用全屏射线遮挡，不能点击地图、出售或开波。界面使用游戏时间为零时仍可响应的 UGUI 控件。两页使用同一 640×800 画框，按安全区等比缩放；CanvasScaler 更新后在渲染前重新定位，避免初次打开使用旧缩放比例。

## 声音与拉条美术

素材位于 `Assets/_Project/Art/Sprites/细胞绘制/设置界面_声音与拉条_v1/`。五张 Sprite 通过 `OpenFieldUiResources` 的 Settings Audio 字段统一引用，五关无需重新拖图。

底槽原生 448×48，内槽 416×16，左右各缩进 16；填充原生 432×32，其中四周 8 像素透明。使用 RectMask2D 裁切固定尺寸的蓝条，裁切宽度为 416×音量，避免低音量时挤压纹理。滑块原生 48×64，中心沿同一个 416 宽范围移动，0% / 100% 两端与内槽一致。底槽使用 Sliced，其 Border 沿用原 .meta。

点击喇叭切换静音；静音或音量为 0 时显示静音图标，其他情况显示声音图标。0 音量显示静音图标不会自动改变静音偏好。静音仍保留滑块值和蓝条显示。界面使用独立组件组装，未直接使用组合预览图。

## 设置文字图片

素材位于 `Assets/_Project/Art/Sprites/细胞绘制/设置界面_文字素材_v1/`。标题“设置”、“总音量”、“全屏”、“恢复默认”、“返回”、喇叭提示、Player 窗口提示、Editor 提示和百分号九张字图，通过 Resources 的 Settings Text 字段引用；按平台选择显示对应提示。

音量百分比复用已有 64×80 像素数字，搭配新 80×80 百分号，等比缩至一半并统一基线；最多三位，靠右显示，不补前导零，只在整数值变化时更新。独立“静音”字图保留为通用素材，当前页面通过喇叭和点击提示表达静音，不额外重复显示该标签。

标题和提示按原生比例显示，其余主要标签及按钮字图缩至一半；所有字图禁用 raycastTarget，事件仍由按钮 / 开关处理。没有修改 TTF / TMP Font Asset。
