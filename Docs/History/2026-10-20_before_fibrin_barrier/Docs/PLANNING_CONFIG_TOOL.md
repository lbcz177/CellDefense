# 策划配置工具

日期：2026-10-15。适用：Unity 2022.3.53f1c1。

## 入口

等待 Unity 导入新脚本后，在顶部菜单栏选择 **胞卫战 → 策划配置**。这是与 Window 同一级的菜单；窗口可以像其他编辑器面板一样拖动、停靠。

窗口左侧列出已有配置，支持按名称或路径搜索；右侧编辑当前选项。刷新列表只重新查找资源，不执行资源安装或自动改写。

## 四个页面

| 页面 | 可改内容 |
| --- | --- |
| 塔 / 细胞 | 名称、ATP 价格、伤害、攻击间隔、射程、选敌方式、生命、接敌容量、是否改路 |
| 敌人 | 名称、生命、基础速度、奖励、漏怪伤害、近战伤害 / 间隔、护甲、破壳时间、护盾、控制抗性、抗原、Boss / 吞噬标识 |
| 关卡 | 初始 ATP、轮间奖励、核心生命、壁垒额度、出售返还比例（0–100%）、速度倍率、信号半径、调试格、可建细胞、三轮顺序及对应波次 |
| 波次 | 单类型敌人 / 数量、逐只间隔、批次间隔，以及可拖动排序的混合分组：敌人、数量、每批数量、组后等待 |

- 护甲和控制比例按百分比填写，例如护甲减伤 25 代表 25%。敌人实际速度 = 基础速度 × 关卡倍率 × 能力加速 × 减速倍率。
- 共享资源的路径会显示在顶部；更改会影响所有引用该资源的关卡。旧版配置也会列出，修改前注意名称与资源路径。
- 减速比例、酸区伤害 / 持续时间、连锁和 Boss 阶段 / 召唤参数仍存放在各 Prefab 策略组件中，可点“打开预制体查看特殊效果”进入原有 Prefab 编辑界面；本窗口不代替这些组件的完整编辑器。
- 高级资源引用默认折叠。当前实际子弹由场景子弹池决定，单改 TowerDefinition 的投射物引用不会切换子弹池模板。

## 保存与撤销

1. 修改会通过 Unity SerializedObject 应用到当前编辑会话，并加入 Undo；**不会自动写入磁盘**。
2. 用窗口“撤销 / 重做”或 Unity 的 Ctrl+Z / Ctrl+Y。它们沿用全局编辑历史，也可能撤销其他 Inspector 中最近的编辑；保存本身不清空历史，撤销已保存的值后需再次保存。
3. 普通资源点“保存当前配置”，只保存当前这个资源。不会调用全项目 SaveAssets，已有其他资源的未保存修改不会被顺带保存。
4. 关卡页只编辑对应已加载场景。未加载时需自行点“打开该关卡”，由 Unity 原生对话框处理当前场景的未保存内容；窗口不会静默切换或覆盖场景。
5. “保存关卡与三轮顺序”保存**整张当前关卡场景**和当前引用的顺序资源，因此也会包含该场景在其他 Inspector 中已有的未保存编辑；不保存其他打开的场景，不自动保存每个波次的内容。
6. 关卡页点“编辑这波”可跳到对应波次，波次内容在波次页单独保存。跳页不会自动保存上个对象，未保存改动仍在当前编辑会话中。
7. 运行或即将进入运行时禁用修改、保存及撤销 / 重做。退出 Play 后再改配置。

窗口显示“有尚未保存的修改 / 当前配置已保存”。底部红色错误表示配置不合法，保存按钮会禁用；修正后可保存。校验不会自动把数值改回推荐值，也不表示数值已经平衡。

## 波次规则

- 空分组列表表示使用单类型配置。添加第一组会复制当前单类型敌人、数量与每批设置。
- 拖动分组左侧改变出怪顺序；计划总数不含 Boss 召唤物。
- 混合分组修改后同步备用数量摘要和首组敌人引用，避免数量显示滞后；不改变旧版 WaveController 不支持混合分组的事实。
- 删除全部分组后回到单类型配置，不是零敌人的空波次。
- 开放关卡必须恰好三轮；目前 Boss 仍有代码中既定的 1 秒入场预告，不在本窗口调整。

用户在 Unity 中检查：

1. 打开菜单，依次查看四页，确认资源名称、关卡顺序和中文字段显示正常。
2. 临时修改一个塔的价格，检查脏标记；撤销 / 重做后保存，再在原 Inspector 核对。
3. 临时填写一个非法数值，确认错误和保存禁用；改回后再保存。
4. 在波次页添加 / 拖动 / 删除分组，检查数量和 Undo；验证完成后撤销试验修改，或明确保存想保留的设置。
5. 在关卡页点“打开该关卡”，核对当前场景路径、关卡速度、额度和四 / 六种塔；编辑三轮顺序及跳转波次，再检查相应保存范围。
6. 另一个资源保留未保存修改时，保存当前资源，确认前者没有被一起保存；进入 Play 后确认窗口不可修改。
