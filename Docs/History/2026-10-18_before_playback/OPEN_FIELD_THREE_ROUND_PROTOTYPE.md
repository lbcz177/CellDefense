# 五关三轮试玩与验收

> 当前操作基线：2026-10-18；对应 [策划 v0.15](GAME_DESIGN_FRAMEWORK.md)。
> 场景及自动测试状态见 [PROJECT_STATUS](PROJECT_STATUS.md)。本文替代旧三关 / 临时 UI 操作，原文在 [历史快照](History/2026-10-18_before_sync/OPEN_FIELD_THREE_ROUND_PROTOTYPE.md)。

## 启动与操作

1. 用 Unity 2022.3.53f1c1 打开项目，打开 Assets/_Project/Scenes/MainMenu.unity，进入 Play。
2. “开始游戏”和“选择关卡”都打开五关列表，可直接选关；返回或 Esc 关闭。也可在编辑器直接打开任一 OpenField 场景。
3. 点击有效空位只打开选塔框；悬停预览，点击选项或选定空位后按数字键建造。第一、二关四种塔，第三至第五关六种。布置和进攻均可建造。
4. 点击已有塔查看属性与射程；点击出售再确认。取消只关闭确认，保留选中塔；右键 / Esc 逐步取消。
5. 点击任一实际入口按钮或 Space 开整波。出怪中按钮隐藏，出怪结束且仍有下一波时可带残敌提前开波。不是只从点击的入口出怪。
6. 末波清场胜利，核心归零失败；Again 重开、Return 返回、前四关 Next 进入下一关，第五关无 Next。

## 手动验收重点

- 五关入口数分别 1 / 2 / 2 / 2 / 3；核心、入口、组织岛和膜边与逻辑格近似对齐，敌人不穿壁垒 / 障碍，塔不压边缘。
- 普通塔占建造格但不改路；只有壁垒改路，累计 6 座，出售不恢复额度。战中不能压敌人当前 / 下一格或封死在场剩余路；改路不瞬移、不清生命 / 状态。
- 普通容量 1、巨噬 2；满额单位继续通过。阵亡 / 出售释放接敌和占用，可补建；死亡不退款。
- 购塔仅成功扣费一次；25 ATP 塔出售返 12。取消、重复确认、塔死亡和同格替换不误售 / 重复退款。
- 采样连线、抗体记忆 / 标记、巨噬吞噬与消化、减速、酸区、神经连锁反馈可辨识。Boss 预告、护盾、抗原变化和召唤计入清场。
- 轮间奖励只发一次；提前开波保留旧敌人，末敌泄露归零失败优先；连续重试 / 返回 / 下一关无旧对象残留。
- 不同窗口下 HUD、菜单和入口按钮可读且不穿透地图；地图当前非等比铺满视口，世界 Sprite / 射程随映射拉伸，屏幕 UI 保持比例。
