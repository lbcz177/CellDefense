## 1. 游戏目标与策略来源

玩家在开放组织地图上自由布置免疫细胞，用可承伤的纤维蛋白壁垒拦住经过的敌群，再通过采样、标记、吞噬、控制和范围攻击守住核心。路线由地图固定障碍决定，当前所有可建单位均不改变寻路。

体验目标是调整摆法与搭配后攻克原本失败的关卡，并获得敌群集中后被清除的成长感。单关期望不超过约 20 分钟，属于待试玩验证的目标。重点决策改为 ATP 的投入位置、壁垒的接敌位置与持续时间、前排保护与损失，以及免疫协作。

2026-10-20 用户授权：将当前改路墙先改成“坚果式”承伤拦截，取消原来的改路额度与拒建约束；旧代码保留，未来另行设计“大蒜式”接触改道单位。候选机制不自动接入本版。

## 3. 单局循环、开波与胜负

进入场景时为 Planning，玩家可布置并手动开第 1 波；Assault 期间也可建造和出售，战斗继续。清场后未到第 3 波则进入下一轮布置；末波出完且所有敌人 / 召唤物退出、核心仍存活时胜利。核心归零始终失败优先。

2026-10-28 用户指定：除第一波外，本波最后一名计划敌人生成后等待 10 秒游戏时间，自动开启下一波，不以清场为条件。入口显示倒计时，仍可点击或按 Space 提前开启；暂停冻结、2× 加速，提前清场不重置计时，最后一波及终局不再安排下一波。见 [自动开波](AUTO_WAVES.md)；此前规则见 [修订前快照](History/2026-10-28_before_auto_waves/GAME_DESIGN_FRAMEWORK.md)。

- 每个实际使用的入口显示开波按钮；点任一入口或按 Space 都开始同一整波，出怪按入口列表轮换。
- 本波仍在计划出怪时隐藏入口按钮；出怪完成且尚有下一波时，允许保留残敌提前开下一波。不会并行运行两份刷怪协程。
- 轮间 ATP 每次进入下一轮只发一次：正常清场时发，带残敌开波则在手动或自动转轮时发；没有额外提前奖励。
- 提前开波保留旧敌人、召唤物及有效路径。最后一波启动或终局隐藏开波按钮。
- 轮间保留已建塔、ATP 和核心生命；布置期默认不自动暂停，冷却、记忆和消化继续计时；玩家可手动暂停。
- 胜负提供重试 / 返回；前四关胜利可进入下一关，第五关不显示下一关。

### 关卡评分与星级

2026-10-25 用户确认采用“击杀表现＋核心剩余生命”，满分 10000。计划波次敌人的击杀比例占 4000 分，胜利时剩余核心生命比例占 6000 分，两项分别向下取整。召唤物不进入评分分子或分母；漏怪、清场和重复回调不增加击杀。暂停、倍速、时长、ATP 及建造 / 出售次数不计分。

通关且总分 ≥ 9000 得三星，≥ 7000 得二星，其余通关得一星；失败零星，核心分为 0，不写入通关记录。结算显示本局分数、星级、分项及该关最高分；每关只保存最高通关分，重打低分或失败不降低纪录。重开清空本局统计，下一关独立计分。

选关页展示最高分与最佳星级，未通关显示暗星。第一关默认开放，后续关卡要求之前的关卡均已通关，不设置分数或星级门槛。成绩存于本地，重启后保留；旧版本无成绩则按未通关显示。规则、存档键和实现见 [关卡评分](LEVEL_SCORING.md)。本次仅更新源码，已上传 0.1.4 APK 不包含此功能。

暂停为独立于波次的状态：布置 / 战斗均可暂停；暂停时冻结游戏时间、禁止建造 / 出售 / 开波，继续恢复此前 1x / 2x。倍率换轮保留，终局、重开、换关、返回菜单与控制器禁用恢复 1x。Esc 在设置页先返回暂停菜单；否则先取消确认或当前选择，没有选择时暂停，暂停菜单内继续。暂停页使用用户 v2 图片，三个按钮均接线；右上工具条使用用户绘制的暂停符号及当前 1× / 2× 图片，悬停 / 按下切换高亮图。见 [暂停与倍速](PAUSE_PLAYBACK.md)。

设置包含总音量 0–100%、保留音量的静音、桌面 Player 无边框全屏 / 窗口切换、恢复默认，并自动保存到本地。默认音量 100%、静音关闭、全屏开启；编辑器不能切换 Player 窗口，显示模式项禁用并提示。主菜单“设置”与战斗暂停页复用同一设置页和偏好，主菜单不改变时间，暂停设置返回后仍暂停；返回 / Esc 回到来源菜单。主菜单设置与选关页互斥。不含独立音乐音量。见 [设置](SETTINGS.md)。

### 第一关新手引导

OpenFieldPrototype 启用可跳过、每次重开重新开始的三轮引导，其他四关不启用。短提示与青色目标框指向有效空格、实际选塔卡片、开波入口或升级按钮；提示随真实选择、建造、死亡 / 出售、升级和换轮推进。引导不暂停时间，不限制自由建造或开波，不发额外资源。

- 第1轮：建议两座近卫交叉覆盖路线，再手动开波；介绍核心生命、击杀收入、战中建造与暂停 / 倍速。
- 第2轮：在近卫射程内布置壁垒，说明 500 生命、全部拦截、不改路及破裂后补建；壁垒死亡 / 出售后重新提示补建。
- 第3轮：加入巨噬，提示末波真菌 Boss 与孢子，增援至四座近卫并介绍伤害升级与确认出售。升级提示可选择“稍后升级”；Boss 不能吞噬。
- 跳过立即隐藏提示及目标框，不改变 ATP、倍率或波次；暂停 / 设置 / 出售确认时隐藏，胜负结束时退出。提示面板阻挡其区域的地图输入，目标框不拦截点击。

这是现有战斗规则上的教学层。首轮实战发现两近卫、一墙、一巨噬和一次升级不足以稳定处理末波，因此补充末轮增援提示；本次不调整敌人、波次、塔参数或经济。操作与验收见 [第一关引导](FIRST_LEVEL_TUTORIAL.md)。

## 4. 建造、承伤壁垒与接敌

### 建造与路线

Planning / Assault 均可点击有效空位打开选塔框，预览射程并扣费建造。有效格须在地图内，且不是核心、入口、固定障碍或已占格；ATP 足够。失败不扣钱。所有可建单位只占建造格，不写入道路阻挡；基础路线仍按固定地形计算。

取消每关累计 6 座壁垒、封路拒建、禁止压敌人当前 / 下一格等旧改路限制。不存在全局塔数或壁垒次数上限；费用、有效格与占位仍约束建造。墙只拦经过自身接敌位置的敌人，不拉回已经走过的单位、不吸引其他通道。

旧 BFS 可达性检查、改路预览、路径替换与保留当前段的 Reroute 保留供未来复用；当前建造、死亡与出售不调用动态改路，UI / 策划配置面板不显示旧改路入口或额度。

### 承伤与拦截

- 普通细胞 100 生命 / 容量 1；巨噬 250 / 容量 2。超额敌人继续通过，之后不回头接战。
- 纤维蛋白壁垒 500 生命 / 30 ATP，不设接敌人数上限；所有经过并被拦住的敌人分别攻击它。敌人越多，累计伤害压力越大。500 为试验起点，待完整试玩调平衡。
- 普通敌人每 1 秒造成 10 伤害，Boss 25；首次伤害等待完整间隔。停顿时不出手，暂停不攻击，不补打累积连击。
- 壁垒保留原有 40% 减速光环，本次不增加输出、回血、修理、击退、移动或额外升级。
- 细胞 / 壁垒死亡立即禁用攻击与光环，释放全部接敌、占用和信号邻接；敌人沿原路线前进，死亡不退款。出售同样释放接敌，并按原规则退款。有效空格可重新建造，无次数额度或死亡冷却。

这是基本接敌拦截，不包含拥挤避让或队列模拟。大蒜式改道、英雄和肉鸽仍属于后续讨论。

## 5. 经济、购买与出售

ATP 来自开局、击杀及轮间奖励，不被动恢复。普通菌 / 高速菌 / 重甲菌击杀奖励为 15 / 12 / 24，三名 Boss 为 60 / 100 / 150，召唤物为 0；以引用 EnemyDefinition 为准。跨关重新初始化经济。

点击已有塔查看属性和射程；出售先二次确认。退款为实际支付的建造费与已支付升级费之和的 50%，整数向下取整，例如 25 → 12、30 → 15。退款不受后续配置价格变化影响。布置和进攻均可出售，终局拒绝；死亡、重复确认、旧确认作用于同格新塔均不产生误售 / 重复退款。出售壁垒立即放行其拦截的敌人，不改变路线。

五关复用现有单次升级：近卫、巨噬、酸化、神经脉冲可 Lv.1 → Lv.2 一次，费用为实付建造价，伤害 +50%，保留原有 1.15 倍视觉缩放。生命 / 射程 / 攻击间隔 / 接敌 / 抗原记忆 / 当前冷却和路径不重置。抗体及壁垒暂未开放升级，不收升级费用。布置和战斗可升级，暂停 / 终局 / 死亡 / 满级 / ATP 不足时拒绝；出售按两笔实付合计退款。完整升级树、移动和主动技能尚未接入，见 [退出与升级](QUIT_AND_UPGRADE.md)。

### 6.1 扩展塔规划：固定支援与单体裂解

2026-10-22用户先将以下两座塔加入策划；2026-10-28已随第二章接入首版代码、Prefab与关卡解锁，参数和实际反馈见[第二章说明](CHAPTER_TWO.md)。第一章保持原塔列表；以下设计目标与风险继续作为后续试玩调整依据，不代表已完成最终平衡或发布APK。

| 规划塔 | 定位 | 核心配合 | 优先级 |
|---|---|---|---|
| 血小板修补塔 | 固定的壁垒支援塔 | 延长选定交战点的守线时间 | 优先验证 |
| 补体裂解塔 | 固定的单体持续组装 / 爆发塔 | 抗体加快组装，壁垒留住目标 | 随合适的新敌人验证 |

#### 血小板修补塔

**设计目标。** 让玩家在增加火力、补建一道墙和维持当前防线之间做选择，重点是支援位置与修补对象，而非全场被动回血。

- 塔本体固定，不攻击敌人；周期性为射程内一座受损纤维蛋白壁垒恢复生命，不超过其最大生命。
- 第一阶段只修补壁垒，不治疗普通细胞、巨噬或核心，也不复活已破裂的墙。
- 可用现有投射物或连接特效表达修补，不生成需要寻路、移动的血小板单位。
- 同一座壁垒可获得的总修补量有限；多座修补塔不能绕过该限制或形成无限叠加，避免永久堵口。
- 自动选目标规则、是否允许玩家指定优先对象、修补过程是否额外消耗 ATP，以及次数 / 总量限制的具体表达仍待讨论。
- 反馈应能看清修补对象、生命恢复及剩余修补能力；不能只有难以察觉的后台数值变化。

**组合与风险。** 壁垒接敌、修补塔争取时间、后排清群；修补不足以代替输出。如果只体现为让墙更耐打，无法形成独立摆放和支援选择，可再评估是否更适合作为壁垒升级分支。

**生物原型与改编。** 血小板与纤维蛋白协作，参与凝块收缩、结构加固与止血；“远程为墙恢复生命”是对这一职责的游戏改编，不是血小板的字面功能。参考：[血小板驱动纤维蛋白凝块收缩研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5668372/)。

#### 补体裂解塔

**设计目标。** 让玩家选择一个值得集中处理的危险目标，并通过识别和拦截为其创造持续攻击窗口；区别于酸区持续群伤和神经连锁攻击。

- 塔本体固定，在射程内选定单个敌人，持续组装攻击结构；完成后造成一次高额单体伤害。
- 已被抗体标记的目标组装更快；无标记时仍能以较慢速度完成，避免离开抗体就完全失效。
- 目标提前死亡、离开射程或被迫换目标时，会损失未完成的组装进度；具体重置 / 保留比例待定，不预设为可跨目标继承。
- 擅长处理能在射程内停留的耐打精英、支援单位；大量脆弱小怪可能使组装频繁中断，效率较低。
- 对 Boss 使用有限伤害，不直接秒杀；伤害类型、与护甲 / 护盾 / 当前易伤的结算关系，以及标记中途消失时的组装规则，接入前另行明确。
- 组装阶段与完成攻击需要可见进度和明确反馈，让玩家理解标记加速与壁垒留人的价值。

**组合与风险。** 近卫采样、抗体标记、壁垒留住危险敌人，补体完成裂解。需要防止它在群伤、持续输出和首领伤害上同时占优，也不将其设计成所有关卡必需的固定搭档。

**生物原型与改编。** 补体是一组蛋白质，膜攻击复合物可在目标表面组装形成孔洞；抗体可参与启动相关过程。真实直接裂解尤其适用于部分革兰阴性菌，不等于对所有细菌、真菌和病毒通用。适合与相应新敌人一起推出；将组装时间、攻击对象和伤害抽象为塔防规则，属于玩法改编。参考：[补体膜攻击复合物的局部组装与细菌杀伤研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7351214/)。

#### 暂缓与验证边界

- 肥大细胞警报塔暂缓：当前没有细胞移动功能，先不引入需要移动、选位与到达时间的增援单位。
- 大蒜式改道塔、英雄和肉鸽继续保留为独立讨论，不随这两座塔自动接入。
- 后续先验证修补是否带来守线投入的取舍，再验证补体的单体处理和免疫协作。当前六塔参数、五关阵容及既有测试结果保持其原有适用范围，不能作为两座新塔已实现或已验收的证据。

#### 第三章补充：两座新细胞（规划，未实现）

成纤维细胞是参与胶原分泌和修复的组织细胞，并非免疫细胞；游戏中作为自身一格的塑形对象改变普通怪路线，有生命、不攻击，死亡 / 出售恢复通行。参考 [NHGRI](https://www.genome.gov/genetics-glossary/Fibroblast)。不增加累计六次额度，需保留各入口和存活普通怪到核心的路径，现有壁垒仍原路承伤不改路。

辅助性 T 首版只加快附近有限巨噬的吞噬消化恢复，不同时加伤害、容量、射程或墙生命，多个支援不叠加；与多建巨噬应有费用和位置上的取舍。两座塔数值、塑形及双路线的实现边界见第三章流程稿。尸体回收暂缓，不随本次细胞扩展加入。
