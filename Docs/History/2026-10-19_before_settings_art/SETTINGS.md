# 设置

日期：2026-10-19；适用五个 OpenField 关卡，优先桌面独立运行。

## 操作

暂停菜单 → 设置。调整即时生效并自动保存，不需要额外点击应用。返回按钮或 Esc 回到暂停菜单，再点返回游戏 / Esc 继续；保持原有 1x / 2x。

| 项目 | 行为 | 默认值 |
|---|---|---|
| 总音量 | 0–100%，控制 AudioListener 总输出，覆盖当前战斗音效 | 100% |
| 静音 | 输出置零，保留滑块音量；取消后恢复该音量；静音时拖动滑块不会自动解除静音 | 关闭 |
| 全屏 | 勾选为无边框全屏，取消为窗口模式；仅桌面 Player 可操作 | 开启 |
| 恢复默认 | 恢复上述三项并立即保存 | — |

编辑器中全屏项禁用并显示“全屏切换在独立运行时生效”，避免把 Game 视图操作描述为独立窗口切换。目前没有背景音乐资产，因此没有单独的音乐音量项。主菜单尚未增加设置入口。

## 代码与保存

- `GameSettings` 在首场景加载前读取 PlayerPrefs，并应用音频和支持平台的显示模式。所有场景共享同一实例，不依赖暂停 UI 存活，不改变 Time.timeScale。
- 保存键前缀为 `CellDefense.Settings.v1`，含 `.Volume`、`.Muted`、`.Fullscreen`；修改 / 恢复默认后调用 PlayerPrefs.Save。音量限制 0–1；非有限数回退为 1。
- `GameSettingsPanel` 使用现有空面板和中文字体，音量滑块、开关和返回 / 默认按钮独立生成。用户已说明声音、拉条有现成图片，目前等待确认保存位置后接入；原有暂停素材及 .meta 保留。
- `OpenFieldPlaybackControls` 管理暂停菜单和设置页的互斥显示；`HandleEscape` 优先关闭设置。恢复、终局、退出和禁用均清除设置页显示状态，下次暂停仍从暂停菜单进入。

设置页与暂停共用全屏射线遮挡，不能点击地图、出售或开波。界面使用游戏时间为零时仍可响应的 UGUI 控件。两页使用同一 640×800 画框，按安全区等比缩放；CanvasScaler 更新后在渲染前重新定位，避免初次打开使用旧缩放比例。
