## 3. 伤害、标记与吞噬

酸性伤害先破壳，再应用外壳减伤、一次 15% 标记易伤、盾吸收和剩余生命伤害。酸化直击与持续酸区都带 Acid 类型；神经带 Neural 类型，其他普通攻击保留原接口。纯标记子弹仍不扣血。

盾恰好被打空时不会向 Health.TakeDamage 传入 0；盾变化回调如果令实例退出或复用，也不会把剩余伤害继续扣到另一条生命。Heal 受最大生命限制，当前生命为 0 的死亡通知期间也不能重新治疗起来。

巨噬通过 CanEngulf / TryEngulf 判断和处决：无盾、允许吞噬且当前生命符合 20 / 50 门槛时直接清除剩余生命，绕过外壳，保留 Died → Exited → 奖励 / 回池。Boss 不可吞噬；成功后仍消化 3 秒。

近卫采样和抗体识别读取 CurrentAntigenId。标记子弹保存发射时抗原，飞行期间变异时不误标记；引用和 SpawnVersion 校验继续存在。变异不会改变共享 Definition 或已出生复制体。

## 4. 波次与召唤

新的混合 groups 使用每组 enemy / count / burstSize / afterDelay，组内 SpawnInterval 和组间 BurstInterval 仍来自波次配置。组与组之间使用 afterDelay；不足六个的组正常等待，换类型不重置入口轮转索引。Boss 放在设计指定的前段 / 中段，并在出生前增加 1 秒入场提示；不会统一等所有杂兵走完才出生。布置期和终局清理提示队列。

召唤继承母体当时的路径、坐标、下一路点及抗原，子单位独立使用自身基础速度与当前关卡倍率。当前同批单位逻辑位置一致，沿同一路段出发；专用出生散开动画尚未制作。不会随机落入障碍或回到入口。

父实例必须仍在当前关卡活跃集合、可攻击且版本一致，路径必须属于本轮。召唤物注册后参与完整清场判定；母体死亡不清除已出生子单位。预告结束前死亡或泄露则取消能力，清场不召唤、不给奖励。每种 Prefab 沿用原闲置敌人池。

## 6. 用户在 Unity 中验证

1. 等待导入，检查 Console；打开 Test Runner → EditMode → EnemyCombatTests，运行边界测试。失败时保留错误与调用栈。
2. 第一关三轮：观察普通菌和高速菌，第三轮出现真菌。跨过 70% / 35% 后各有一次预告和 3 个孢子；母体死亡后有存活孢子时不胜利。
3. 第二关第二轮：重甲每次普通 25 伤害扣 18.75；标记中扣 21.5625。无盾并达到吞噬门槛时一次清除，不因外壳留下残血。
4. 第二关第三轮：生物膜 Boss 初始盾 80；预告后补自身到 80、最多三个同伴到 40。重复补盾不变成 80 / 120 叠加；治疗不超上限，破盾 / 授盾有状态反馈。
5. 第三关：酸化命中重甲立即破壳，绿圈范围持续伤害也刷新破壳；停止酸性命中 3 秒后恢复外壳。神经连锁与普通输出仍可增伤 / 削盾。
6. 第三关第三轮：病毒母体先复制 4 个 A 类单位；变异预告后切换 B，清掉自身标记；重新采样后可以重新标记。早先 A 类复制体身份不变，旧飞行抗体不误标记。后段再复制 4 个并加速，一共不超过 8 个。出怪序列最后追加 1 只变异超级真菌，有独立入场预告，沿用两次各 3 个孢子的能力；所有 Boss 和召唤物清除后才胜利。
7. 所有 Boss 不可吞噬；减速 / 停顿只生效一半，仍遵守恢复窗口。暂停冻结预告和能力，不一次补发多轮支援或召唤。
8. 检查八种泄露伤害为 1 / 1 / 2 / 1 / 1 / 5 / 6 / 8，核心不足时归零且失败优先；击杀召唤物不给 ATP。
9. 死亡回池再出生：满血、默认抗原和防御、第一阶段、无旧标记 / 控制 / 待执行能力。重开、切关和返回后没有旧血条 / 脉冲残留。
10. 检查第一 / 二关原三塔是否能处理当前压力，第三关六塔搭配是否明显有效，再调 HP、速度、组间等待和资源。保留实际试玩记录，避免把设计目标写成已验收。
