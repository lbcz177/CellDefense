# 有限改路与细胞承伤：v0.14 接入说明

日期：2026-10-15。工程：Unity 2022.3.53f1c1，分支 codex/open-field-prototype。

依据 [策划 v0.14](GAME_DESIGN_FRAMEWORK.md) 及用户本轮选择实现。仅完成代码 / 资产接入与静态检查；不启动 Unity、Play、Test Runner、Player 构建或 Profiler。

## 1. 已确认的试验规则

| 对象 | 生命 / 额度 | 接敌 / 改路 |
| --- | --- | --- |
| 纤维蛋白壁垒 | 每关累计限建 6 座，每座仍花 30 ATP | 唯一改变道路的塔，保留减速光环；当前不接敌、不被近战攻击 |
| 近卫、抗体、酸化、神经 | 生命 100 | 每座最多接敌 1 个，不阻挡寻路 |
| 巨噬 | 生命 250 | 最多接敌 2 个，保留原普通攻击、吞噬和消化 |
| 普通敌人 / 孢子 / 复制体 | 每次近战伤害 10，间隔 1 秒 | 仅攻击当前路径路段上的细胞 |
| 三种 Boss | 每次近战伤害 25，间隔 1 秒 | 同样占一个接敌名额，阶段 / 召唤照常工作 |

- 三关每关壁垒额度都是 6，成功建造才扣 ATP 和额度；失败回滚，两者都不扣。
- 额度与 ATP 独立，不因击杀或轮间奖励增长，也不因换轮重置；重开 / 下一关重置。
- 当前没有出售 / 移动 / 额度回收入口，不改变尚未确定的回收规则。
- 所有入口必须可达；不允许完全封路、动态拆墙或主动追击路外单位。2026-10-16 起按用户要求允许战中建塔，壁垒同时保证在场敌人仍可达核心，详见 [战斗中建塔](LIVE_BUILD_IMPLEMENTATION.md)。
- 当前壁垒通过绕路避免接敌，不能据此推定今后永远无敌；突破规则尚未确定。
- 普通细胞承伤和容量参数是用户选定的试验起点，未做难度平衡。

## 2. 实际行为

建造占位与通行阻挡分开：普通细胞所在格不可再建另一座塔，但 BFS 可以经过；壁垒所在格不可通行。

敌人沿原路线进入细胞附近（逻辑接战半径 0.45 格）时尝试占一个名额。名额可用则停止移动，接战满 1 秒后第一次攻击；之后每秒一次。停顿期间不攻击，暂停期间不推进计时；长帧恢复只结算一次，不补发积攒攻击。

容量已满的敌人承诺通过该细胞，不因途中有人释放名额而回头接敌。新进入的后续敌人可以使用空出的名额。格子不会变成永久障碍，Boss 也不绕过接敌规则。

细胞生命归零立即禁用整个对象，停止控制器、动画释放和策略光环；关卡移除其登记、BuildSlot、信号邻接与建造占位，再销毁对象。死亡不退款，生命不会轮间自动补满；下个布置阶段可在空出的格上补建。普通细胞不改路，死亡后正在行进的敌人无需重新寻路。

敌人死亡、泄露、清场、回池或重新初始化都会释放其旧接敌关系；名额由引用和 SpawnVersion 共同判断，旧版本释放不能移除新版本关系。召唤物从母体当前路段出生，接入同一套规则。

## 3. 文件与职责

| 文件 | 职责 |
| --- | --- |
| OpenFieldGridModel | occupied 仅表示建造占位；routeBlocked 表示壁垒；Revision 使检查缓存失效；候选路线计算后恢复真实距离场 |
| TowerDefinition | BlocksEnemyRoute、MaxHealth、InterceptCapacity；纤维壁垒显式改路，巨噬显式 250 / 2，其余默认 100 / 1 |
| EnemyDefinition | ContactDamage、ContactAttackInterval；普通默认 10 / 1，Boss 资产显式 25 / 1 |
| TowerCombatState | 当前生命、接敌名额与版本、死亡事件、即时禁用 |
| EnemyContactCombat | 当前接敌 / 溢出通过、伤害时钟、存活 / 阶段 / 版本校验、退出与禁用清理 |
| PathFollower.BeforeMove | 在实际下一段移动前检查接敌，可停止当前移动；旧场景留空，不安装新接战系统 |
| OpenFieldPrototypeController | 额度、登记、建造事务、死亡移除、敌人入场接战配置、信号重建 |
| OpenFieldPresentation | 布置期蓝色现有路线、悬停有效壁垒时黄色候选路线；开战与终局隐藏 |
| OpenFieldBuildMenu | 职责与拒绝原因、图标 / 价格、可用状态，不自行扣费 |
| EnemyStatusHud | 中文壁垒额度、细胞生命 / 接敌数量；显示层无点击接收 |

TowerCombatState 在开放地图建造后添加 / 初始化，EnemyContactCombat 在开放地图敌人入场后添加一次并在每次复用时重新配置；不改已有 Prefab 的组件接线。旧固定路线场景不启用承伤系统。新脚本已有 .meta，没有修改或生成图片。

## 6. 用户在 Unity 中验证

1. 退出 Play 并等待导入，先看 Console；运行 EditMode → EnemyCombatTests（21 项），保留失败调用栈。
2. 第一 / 二关选塔框有四项，第三关六项；普通细胞卡片注明接敌容量，壁垒注明改路 / 额度。
3. 观察蓝色路线。在路线格选近卫，路线不变；选壁垒时黄色预览绕开该格，取消后恢复蓝色真实路线。
4. 放置壁垒不得封死任何入口；会封路的选项置灰并解释原因，不扣 ATP / 额度。
5. 资源足够时累计建 6 座，第 7 座禁用；普通塔仍可建。换轮、击杀和奖励不会恢复额度，重开恢复到 6。
6. 在路径上放普通细胞，敌人进入后停下；第 1 秒前不扣血，普通每秒扣 10。第二名超过容量继续走。
7. 巨噬最多同时接敌两名，第三名继续；接战敌人被其他塔杀死后空出名额，新进入者可接战。
8. 让细胞死亡：血条消失，攻击和效果停止，接战敌人继续原路线；下一布置期该格可补建，死去的细胞不再转发抗原。
9. Boss 每秒扣 25，接战时仍能进入阶段与有限召唤；神经停顿能暂时阻止其近战出手。母体与子单位都参与清场。
10. 连续重开 / 下一关，检查额度、细胞登记、敌人名额、路线和血条无上局残留，再记录布局收益与损失压力。
