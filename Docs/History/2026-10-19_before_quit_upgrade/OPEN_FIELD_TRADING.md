# 复用原 Level02 的购塔与出售规则

日期：2026-10-17；Unity 2022.3.53f1c1。

用户要求把原版 `Level02` 的购塔、出售规则复用到第一至第五个开放关卡。

## 复用的规则

- 空位选塔，显示配置价格，ATP 不足时禁止购买；购买成功扣费、生成塔并收起选择，失败不重复扣费。
- 点击已有塔，显示名称、生命、射程、当前伤害和攻击间隔，并显示射程圈；重复点击同一塔或右键 / Esc 关闭。
- 点击出售后显示二次确认与退款金额；取消或点击对话框外只关闭确认，保留当前塔选择。
- 返还实际建造投入与已支付升级费用总和的 50%，整数除法向下取整：25 ATP → 12，30 ATP → 15，40 ATP → 20。读取塔保存的支付记录，后续修改 Definition 价格不会改变退款基数。
- 确认时再次核对当前选择与原待售塔。取消、重复确认、塔死亡后确认、同格新塔出现后旧确认均不重复退款或误卖。

原 Level02 的 `sellRefundPercent` 实际配置为 50，五个开放场景也明确配置为 50。`TowerEconomyRules` 为新旧流程共同提供价格校验和退款算法；原 BuildController 的购塔 / 出售入口继续使用原有状态和塔位校验。

## 开放地图接入

- 布置和进攻均可购塔 / 出售，终局禁止；保留开放地图自由选格、占用和可达性规则。
- 壁垒出售后更新入口及在场敌人的剩余路线，保留当前位置、复用版本和当前路段。
- 壁垒额度仍为整关累计建造额度，出售不返还；此额度是开放地图既有规则，原 Level02 没有对应额度。
- 出售立即禁用塔，停止攻击和效果刷新、清理酸区、解除接敌 / 溢出引用，移除建造占位与信号邻接，再退款。减速按最近一次刷新的短时有效期自然过期，已发出的投射物沿用原有结算规则。
- 细胞被打毁只清理占位与选择，不发放出售退款。确认出售期间死亡也会关闭对话框。
- 数据 HUD 预制体和入口开波按钮保留；塔操作面板跟随塔的屏幕投影，并避让 HUD 和屏幕边界，确认界面阻挡地图点击。

策划配置工具的关卡页增加“出售返还比例（%）”，范围 0–100；此项按关卡保存。旧关卡的固定组织 / 路面塔位限制继续由旧 BuildController 处理，开放地图仍使用当前网格规则。
