# 战斗中建塔与动态路线

> 2026-10-20 适用范围更新：纤维蛋白已改为 500 生命、30 ATP 的全部拦截壁垒，无累计额度；不改路。旧改路实现和测试按历史保留，不作为当前壁垒规则；隐藏字段与旧路径算法供未来复用。当前说明见 [FIBRIN_BARRIER](FIBRIN_BARRIER.md)。

2026-10-16，按用户要求：布置 / 进攻期间均可点击空位选塔、预览和建造，战斗不暂停。胜利 / 失败时关闭建造。塔、敌人、波次、ATP 价格和壁垒累计 6 座额度保持。

## 路线规则

- 普通细胞可被穿过，建成即加入战斗及接敌查询，不修改敌人路径。
- 壁垒不能放在在场敌人的当前格或下一目标格；必须同时保证每个入口、每个在场敌人的下一节点可达核心，避免封住已经越过岔口的敌人。
- 壁垒建成后为后续出怪重建入口路径，并为在场敌人按下一节点共享剩余路径。敌人先完成当前路段，随后沿新路径前进，不瞬移、不重新 Initialize，不改变生命、SpawnVersion、速度修正、减速、眩晕或接敌回调。
- 重建先准备所有新路径，再切换引用、清理旧路径。Boss 召唤物从母体当前新路径进度出生，正常计入清场；提前开波复用当前路径。
- 选中建造格时可预览当前 / 候选路线，取消选择后进攻期隐藏路线。死亡的普通细胞格可立即补建，仍不退款。

## 修改点

- `OpenFieldPrototypeController.CanBuild`：统一布置 / 进攻输入与建造入口的阶段判断。
- `OpenFieldGridModel.CheckPlacementKeepingRoutes`：额外检查在场敌人的必要节点可达性。
- `PathFollower.Reroute`：保留当前位置、下一节点与战斗状态，仅替换路径和目标索引。
- `OpenFieldPrototypeController.RebuildAssaultRoutes`：入口 / 在场共享路径及召唤请求引用维护。
- [HUD 预制体](BATTLE_HUD_ART_IMPLEMENTATION.md)：五关场景引用，外框宽度缩小 20%，额度提示一并预制。
