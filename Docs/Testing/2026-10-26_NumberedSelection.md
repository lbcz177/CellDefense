# 序号选关与详情验证

Unity 2022.3.53f1c1，以 Android 为当前目标，在 `Logs/CodexTradingTests` 隔离副本中使用 D3D11 运行。该副本使用独立公司／产品名 `CellDefenseValidation / NumberedSelectionTests`，未向主工程玩家记录写入演示分数。

最终 PlayMode **9／9 通过，0 失败**。覆盖新的序号选择／详情交互两项、原有主菜单设置三项、评分与五关流程四项。结果见 [PlayMode XML](2026-10-26_NumberedSelection_playmode.xml)。

- 点击 1—5 只打开所选详情，不加载战斗；详情启动按钮才进入对应场景。
- 详情读取最新历史最高分及最佳星级；未通关记录显示“未通关”，不伪造零分。
- 模态层阻止底层操作，返回／Esc 恢复焦点，关闭选关同时关闭详情。
- 1280×720、640×480、2048×928 下检查面板边界与像素字图无缺字；超宽屏启用手机预览及自定义安全区。
- 原有设置共享、关闭／销毁清理、退出条件，以及五关真实波次评分、重试和最高分保留仍通过。

实际截图保存于 `Assets/_Project/Art/Sprites/细胞绘制/章节选关_序号与详情_2026-10-26_v2/运行验证_v3~/`。9600／9800 为隔离测试中的临时记录，各测试后恢复。美术示意中的 9600 同样不是用户真实成绩。

首轮发现旧设置测试仍按“一点关卡即进入战斗”操作，已更新为显式启动；第二轮发现新增“章”字不在既有动态字图中，运行页头改用章节名避免缺字。最终复测通过，旧结果保留在 `Logs/NumberedSelection20261026/`。

代码接入限于已有五关；第二、三章仍为美术与策划，未新增可玩场景、波次、解锁门槛或逐局历史存储，未构建或发布 APK。
