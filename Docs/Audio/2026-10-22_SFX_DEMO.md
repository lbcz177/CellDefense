# 胞卫战音效试听 v1

2026-10-22 制作：柔软、弹性、轻微电子感的原创程序合成音效。仅制作试听素材，尚未替换游戏内音效。

- [离线试听页面](2026-10-22_细胞音效试听.html)：13 个用途卡片，17 个独立音效，以及顺序试听与密集战斗混音。页面音频已内嵌，播放一个时会暂停其他播放器。
- 素材目录：`Assets/_Project/Audio/SFX/细胞音效试听_2026-10-22_v1/`。
- 合成源代码：`Tools/Audio/generate_cell_sfx_demo.py`，依赖 NumPy，使用固定随机种子。同名文件内容不同时拒绝覆盖，保留原素材及 Unity `.meta`。

| 类别 | 音效 |
|---|---|
| 操作 | 点击、建造、升级、出售 |
| 战斗 | 细胞发射（三变体）、黏液命中（三变体）、巨噬吞噬、壁垒破裂 |
| 状态与结算 | 开波、Boss 警报、核心受击、胜利、失败 |

独立文件采用 48 kHz / 16-bit / 单声道 PCM WAV。峰值约 -11.37 至 -5.35 dBFS，使用短淡入淡出。高频战斗音效控制在 0.15–0.20 秒；接入时还需结合实际战斗调整播放频率、混音优先级和音量。

`试听~` 子目录被 Unity 忽略，包含 15.02 秒顺序试听 WAV、压缩 MP3、8 秒双声道战斗混音，以及逐文件 SHA-256、响度统计和格式检查记录。战斗混音为离线编排的叠加听感示例，不代表游戏内音频调度已实现。

检查结果：17 个独立 WAV、13 个试听卡片和 19 个内嵌播放器全部通过格式与完整性检查；无满幅削波，独立 WAV 首尾归零。
