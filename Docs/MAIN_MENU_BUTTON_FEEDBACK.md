# 主界面按钮选中反馈（2026-10-29）

开始游戏、细胞图鉴、设置和退出是烘焙背景上的透明点击区域，透明图片的变色无法表达选中状态。统一通过不拦截点击的UGUI图形叠加浅金色角框与轻微底色，按下时加强反馈。

用户指出重做后的开始按钮与原美术差异太大，已撤销新底板和文字覆盖，恢复原来的蓝底、黄色箭头及粗像素字。之前已绘的独立素材位于`Assets/_Project/Art/Sprites/细胞绘制/主界面/按钮_v1/01_开始游戏_v1.png`；目前背景中的同款按钮保持可见，不另叠加不同字体或底板，原图和`.meta`均保留。

- 首次进入不主动高亮，鼠标悬停时只突出当前按钮，移开后恢复。
- 方向键、Tab循环切换四个入口；Shift+Tab反向，Enter使用原按钮提交逻辑。
- 鼠标进入另一按钮时清除旧键盘高亮；触控抬起或滑出后不保留悬停。
- 打开选章、图鉴或设置时清除主菜单指针反馈；鼠标操作返回后不因EventSystem残留选中而亮起。键盘进入弹窗时，返回可恢复来源焦点。
- 反馈图形随按钮及移动安全区布局缩放，不修改原按钮点击绑定，不新增主菜单入口。

实现：`MainMenuController`管理输入焦点，`MainMenuButtonFeedback`处理指针与选择事件，`MainMenuFocusGraphic`绘制角框。验证用例在`MainMenuFocusPlayModeTests`，覆盖三种横屏尺寸、触控、鼠标、键盘和弹窗返回。

最终菜单相关PlayMode专项13/13通过，包含实际反馈网格绘制、设置、图鉴与章节流程；640×480、1280×720、2048×928截图已查看。见[测试XML](Testing/2026-10-29_MainMenuFocus_playmode.xml)和[源码校验](Testing/2026-10-29_MainMenuFocus_summary.json)。本次未重新打包APK。
