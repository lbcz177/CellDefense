# 顺序通关与关卡解锁（2026-10-28）

按用户新要求，可玩关卡采用顺序解锁，替代此前自由选关约定。2026-10-28第二章接入后，范围扩展为第一章五关→第二章四关，共九关。

- 第一关默认可玩；每关之前的所有关卡都有胜利纪录，才可进入该关。
- 通关即可，不要求二星、三星或分数门槛；失败、中途退出不会解锁。
- 已通关关卡可以重打，最高分与最佳星级继续保留。
- 未开放序号变灰，显示“未开放”。按钮、详情入口、开始方法及战斗“下一关”方法均核验解锁条件，不能只绕过按钮状态进入。
- 直接使用现有 `BestScore` 键是否存在作为通关事实，不新增解锁存档，不推断或补写不存在的通关纪录。重新启动仍按本地纪录恢复。
- 旧自由选关产生的后期成绩保留；若之前的关卡缺少通关纪录，仍需先补齐前面的关卡。
- 第二章接在第一章第五关之后逐关开放，使用同一存档和解锁规则；第三章继续仅预览，不可开始战斗。见[第二章](CHAPTER_TWO.md)。

规则集中在 `LevelProgress.IsUnlocked`。胜利结算仍先保存纪录，因此正常通关后可立刻进入下一关；打开选关页时重新读取，不缓存旧锁定状态。
