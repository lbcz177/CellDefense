# 防御塔与怪物机制候选库

> 候选稿 v0.1 · 2026-10-29；配套策划 v0.31。用户要求先收录此前讨论的五种防御方向和六种怪物，加入时间待定。所有条目的制作时间、解锁关卡、数值与验证安排均未定，不自动加入当前章节或形成制作任务。本次仅更新文档。

## 1. 范围与现状

防御候选包含三种新增方向，以及 NK / 嗜酸性粒细胞原候选的机制细化。网捕是中性粒细胞专精，中和型浆细胞是 B 系分化方向，不冒充两个全新细胞身份；独立建造还是升级分支均待定。

当前第三章已有炎症、辅助 T 与 Treg，运行规则见 [第三章首版](../CHAPTER_THREE.md)。另有“组织重塑与协同”的重排方案，见 [流程稿](CHAPTER_THREE_FLOW_2026-10-29.md)；本次不迁移、替换或重新编号任何关卡，也不把流程稿写成运行现状。辅助 T 现行抗体标记支援与此前巨噬支援方案的差别不在本次改动范围。

改路仍保留为可行设计方向，永久塑形与临时改道尚需比较；此前讨论的“持续时间＋冷却”不是已确定替代方案。本候选库不调整成纤维细胞、承伤壁垒、溶纤先导的既有方案。尸体回收、死亡返还 ATP 与细胞移动继续暂缓。

真实细胞、病原体及分子过程是灵感来源；短时束缚、范围、攻击弹道、倒计时、标记门槛和阶段转换等是玩法抽象。仅有生物学机制不代表每一株同种病原体都具有同等能力，也不意味着具有对应能力的细胞只能处理一种敌人。

## 2. 防御候选：五种方向，解锁均待定

### T-C01 网捕型中性粒细胞：短时捕获

- **原型：** 中性粒细胞可释放胞外诱捕网（NETs），捕获微生物。[原始研究](https://pubmed.ncbi.nlm.nih.gov/15001782/)
- **身份：** 已有近卫的专精候选，独立建造或升级分支未定。
- **机制：** 向敌群释放小片短时网，束缚有限目标，直接伤害较低。既不改变路线，也不依靠墙式生命持续阻挡。
- **用途：** 接高速漏怪，或让酸区 / 定向攻击获得额外输出窗口。
- **限制：** 同一目标需要控制恢复窗口，Boss 效果减弱；多网不能轮流永控。费用、捕获数量、时长和冷却待定，不同时加入自杀与尸体系统。
- **待比较：** 多买输出与延长已有火力窗口的收益，是否在墙破后的补救和侧路保护中有独立价值。

### T-C02 中和型浆细胞：保护后排

- **原型：** 浆细胞为抗体分泌细胞；部分抗体可中和相应细菌毒素，阻止其作用于细胞。[中和机制研究](https://pubmed.ncbi.nlm.nih.gov/6207425/)
- **身份：** B 系另一分化方向，独立建造或分支未定；现有 B 塔继续负责标记。
- **机制：** 优先试验拦截有限范围内特定类型的毒素弹，单位时间内处理数量有限。
- **用途：** 保护输出 / 支援密集区，给提前击杀来源之外的另一种选择。
- **限制：** 不回血、不修墙、不净化全部负面状态；不默认中和溶纤技能、所有蛋白酶或所有攻击。毒素浓度 / 数量超过处理能力仍可突破。
- **待比较：** 保护阵地的投入与多建输出、分散布置的收益。首版只选一种可读毒素攻击，不同时新增多套异常状态。

### T-C03 潘氏细胞：有方向的短程清群

- **原型：** 位于小肠隐窝的上皮细胞，可分泌防御素、溶菌酶等抗微生物物质，并非新免疫白细胞。[原始研究](https://journals.asm.org/doi/full/10.1128/iai.71.3.1109-1115.2003)
- **机制：** 前方短扇面齐射，一次覆盖多个目标，攻击间隔明显；选择朝向或施法方向的具体操作待定。
- **用途：** 同向密集敌群与特定拐角，促使玩家关注敌人排列和塔的朝向。
- **限制：** 侧面 / 背面覆盖弱，分散精英与相对双路需要其他火力补足；射程形状是游戏改编。
- **待比较：** 与酸区持续伤害、神经连锁的差异。肠道主题仅为适配条件，不预定章节或立即制作新场景。

### T-C04 NK 细胞：优先清源

- **原型：** 杀伤病毒感染细胞及肿瘤细胞。[NCI 介绍](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/nk-cell)
- **机制细化：** 范围内优先攻击明确可辨识的感染宿主，需要一定攻击 / 接触时间；不隔地图点杀来源，对普通沿路细菌不享有同等专长。
- **用途：** 先部署清除感染源，或先守路线、后处理持续压力之间的取舍。
- **条件：** 先有可清除、产敌有预告的感染宿主；现有病毒粒子 / 母体不直接等同此系统。与 CD8 先择一的原方向保留，但本候选不新增固定解锁关号。

### T-C05 嗜酸性粒细胞：持续压制大型目标

- **原型：** 参与抵御部分寄生虫，可释放细胞毒性颗粒。[英国免疫学会介绍](https://www.immunology.org/public-information/bitesized-immunology/cells/eosinophils)
- **机制细化：** 对同一大型目标持续释放颗粒，保持攻击时逐步提高效率；换目标后需重新建立效果。
- **用途：** 比较靠前提早接触与靠后安全输出，对停留较久的大型目标有效。
- **限制：** 对小怪切换频繁时收益较低；与补体“组装完成后爆发”区别开。持续增益上限、换目标损失与伤害规则均待定。
- **条件：** 需适合的大型敌人主题，具体寄生虫种类与章节未定，不把所有 Boss 都设计成必须靠它处理。

## 3. 怪物候选：六种类型，加入时间均待定

### E-C01 荚膜肺炎链球菌：防吞噬型

- **原型：** 荚膜与逃避调理吞噬有关。[研究](https://pubmed.ncbi.nlm.nih.gov/17088346/)
- **轮廓：** 相连双球菌外有半透明荚膜，状态同时以图标辨识。
- **行为：** 中等生命、正常推进；不额外增加物理护甲。
- **玩法规则：** 未有效标记时不可吞噬，被标记后恢复既有吞噬生命门槛，普通伤害正常生效。此确定门槛是玩法改编，不是抗体作用的通用生物结论。
- **应对：** 近卫—B—巨噬协作，或更多直接火力；酸化破甲不自动剥除荚膜。
- **混编作用：** 降低巨噬连续处理普通群的效率，不全面克制所有输出。

### E-C02 产毒型金黄色葡萄球菌：攻击防御细胞型

- **原型：** 部分金黄色葡萄球菌毒素可损伤免疫细胞。[原始研究](https://pubmed.ncbi.nlm.nih.gov/23509138/)
- **轮廓：** 葡萄状菌团，释放攻击前有明确聚集动作。
- **行为：** 接近有限距离内的防御细胞后停下，预警后释放毒素攻击；不是全程只朝核心移动。
- **应对：** 提前击杀、分散后排、调整塔位，也可由中和型浆细胞处理适配毒素；不能只允许新塔应对。
- **限制：** 偏低生命，攻击附近目标，不隔全图精准点杀最贵塔。弹道与攻击距离是玩法抽象，首版不同时叠加腐蚀、禁疗、感染等多状态。

### E-C03 群感型铜绿假单胞菌：聚集强化型

- **原型：** 群体感应参与部分毒力相关基因调节。[原始研究](https://pubmed.ncbi.nlm.nih.gov/9190808/)
- **轮廓：** 杆状菌，聚集并准备强化时出现短信号连线与图标。
- **行为：** 单只较弱，同类在小范围达到一定数量后先预警，再获得有限接敌攻击效率增益；同类减少后增益消退。
- **应对：** 入口削减数量，或集中后及时 AOE 清除，形成聚怪收益与墙承伤压力之间的取舍。
- **限制：** 同类阈值、范围、倍率和退出宽限待定，有上限且不多层叠加。首版不同时回血、授盾或加速；密度阈值与即时增伤均为游戏改编。

### E-C04 菌丝型白色念珠菌：定向侵袭型

- **原型：** 菌丝形态与念珠菌溶素相关上皮损伤。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4851236/)
- **轮廓：** 初始圆润菌体，攻击时出现清楚的伸长菌丝。
- **行为：** 沿路线移动，到交战区停下，标出方向再伸出有限长度菌丝，对该方向的防御位置施压。
- **应对：** 侧翼火力、分散布置，或展开完成前击杀；区别于现有真菌 Boss 的播散孢子。
- **限制：** 预告后方向锁定，不追着新建塔连续转向；不无限穿透整排，不自动增殖成满地图菌丝。伤害形状与预告是游戏改编。

### E-C05 解网型化脓性链球菌：局部解控精英

- **原型：** 部分菌株 DNase 可降解 NETs。[原始研究](https://pubmed.ncbi.nlm.nih.gov/16488874/)
- **轮廓：** 短菌链，释放能力时以网丝断裂表现。
- **行为：** 少量混编，进入网区后预警，局部削弱 NET，帮助有限敌人脱离捕获。
- **应对：** 提前削减血量，或用壁垒、神经控制及直接伤害接住突破。
- **限制：** 不解除全图网、不同时免疫神经控制、不溶解纤维蛋白。与溶纤先导为同种病原体不同玩法特化，不自动合并技能。
- **依赖：** 网捕先有实际用途再验证此精英，不因两者同时收录就让每波都携带解网怪。

### E-C06 艰难梭菌芽孢：阶段转换型

- **原型：** 芽孢在适宜条件下萌发为营养细胞。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4333439/)
- **轮廓：** 初始紧凑芽孢，明确转化后露出杆状菌体。
- **行为：** 初期慢速、较强防护，经过可见倒计时转为防护降低、推进更积极的活跃阶段。
- **应对：** 沿路提前削弱，或将主火力放在转化后的交战区，改变对长路线和攻击位置的判断。
- **限制：** 两形态视为同一敌人，转化保留已受伤害，不回满血、不再次给钱或重复计分；伤害 / 生命具体继承方式待定。首版不加分裂与产毒，也不把游戏倒计时描述为真实萌发条件。
- **依赖：** 肠道仅为主题适配方向，章节与制作时间未定。

## 4. 配合与筛选原则

荚膜型可复用已有标记 / 吞噬链；群感型可用已有酸区与连锁处理，网捕只是另一种配合。产毒型可通过早杀和分散应对，中和型不成为唯一钥匙。菌丝型先验证侧翼与攻击方向，解网型待 NET 成立后再试。NK 与嗜酸性粒细胞需要对应敌人对象，但不因候选入库而自动新增宿主 / 寄生虫系统。

所有条目的费用、生命、伤害、射程、时间、数量、解锁关卡、制作顺序与日期均待定，不沿用此前口头讨论的优先制作建议。先证明每类敌人带来不同判断，并保留可用的旧塔解法；不要求每种怪都有一座专用克制塔，不以大量全免疫抹掉已有阵容。

本次不修改章节流程稿、场景、单位配置、菜单、存档或测试。当前条目均无玩法实现和数值验收；后续决定采用某项时，再做单机制小规模验证及经济、视觉和操作检查。
