# 第三章：组织重塑与协同，以及后续流程

> 流程稿 v0.1 · 2026-10-29；配套策划 v0.30。用户认可第三章四关“塑形—协同—破障—首领”的方向，要求写入并细化后几关。本稿为待实现设计；波数、时长、数量、数值和后续章规模是试验起点。本次不改现有九关、预览菜单、场景、美术、存档或发布包。

## 1. 本轮流程决策

- 第一、二章可玩流程保持，接入现状见 [第二章说明](../CHAPTER_TWO.md)。
- 第三章改为“组织重塑与协同”，新增成纤维细胞与辅助性 T 细胞，介绍坚持基础路线的先导怪，章末为化脓性链球菌·溶纤先导。
- 原第三章炎症内容顺延为第四章“免疫平衡”，辅助 T 已在第三章介绍，第四章不重复解锁；Treg 等炎症原型通过后再接入。
- 感染宿主与 NK / CD8 方向顺延至第五章储备，先择一；寄生虫仍为远期可选。
- 尸体回收、死亡返还 ATP、移动回收暂缓，不作为第三章前置。英雄、细胞移动、肉鸽与被动 ATP 收入也不随本次排程加入。

章节按学习过程安排，不代表现实免疫系统按此顺序发生。阶段性目标是先完成有趣的 3-1，再制作后续，不一次承诺全部远期章节。

## 2. 新单位与双路线规则

### 2.1 成纤维细胞：一格塑形

真实原型参与结缔组织形成、胶原分泌与伤口修复，是组织细胞，不归为免疫细胞。参考 [NHGRI](https://www.genome.gov/genetics-glossary/Fibroblast)。即时改变一格通行性是游戏改编。

第一版将细胞和自身格形成的基质作为同一个可建对象：有生命、不攻击、不主动修墙；普通敌人绕开此格，死亡或出售后恢复通行。纤维蛋白壁垒仍只原路承伤，不改变寻路。辅助 T 不强化塑形或壁垒生命。

不增加累计建造六次等额度。费用、占格和保护成本约束投入；新塑形规则要求所有入口与存活普通敌人仍能到达核心，不允许彻底封死，也不能直接在敌人占据的格子上生成塑形障碍。此约束仅针对新增塑形对象，不重新限制现有承伤壁垒。

建造预览应显示普通敌人的路线变化和非法原因。死亡 / 出售后路径平滑更新，保留敌人当前位置与当前移动段，不瞬移、不集体倒退；确切重接节点需实现验证。反复出售改路是否可低成本无限拖延，需作为玩法检查，不能仅验证 BFS 可达。

### 2.2 辅助性 T：巨噬支援

真实辅助性 T 参与支持巨噬、B 等免疫反应，参考 [NCI](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/helper-t-cell)。首版专注巨噬吞噬后的消化恢复加快，属于玩法抽象；先不同时增加伤害、射程、生命、接敌容量或 B 标记效率。

建议有限范围最多支持两座巨噬作为试验起点，多个辅助 T 对同一巨噬不叠加；目标连线 / 图标应可见，离开支援范围或支援塔阵亡后恢复基础消化规则。射程、加速幅度、费用与生命待标定；不能用无限加速或免除消化使其替代全部输出。Boss 仍不可吞噬。

有效条件应是“已有巨噬能吞掉目标，但恢复跟不上连续敌群”；首次教学使用可标记的普通菌，不用吞噬免疫敌人展示它。允许多建巨噬或增加范围火力形成替代解法。

### 2.3 先导怪与 Boss：坚持基础路线

每个入口的基础路线，取地图加载后由固定组织障碍计算的无玩家塑形路线，保持稳定；普通怪使用受塑形影响的动态路线。先导怪与本章 Boss 走所属入口的基础路线，遇到塑形细胞本体或壁垒按接敌规则攻击。它们不追杀基础路线外的塑形细胞，不穿越固定组织岛，也不默认获得免控、重甲或远程拆塔。

先导怪是先验证玩法的独立普通敌型，具体病原体名称待定，不把“坚持原路”宣称为真实细菌本能。本章不同时给它局部溶纤，以便普通破障与 Boss 的生物技能职责清楚。

Boss 额外技能仅对纤维蛋白壁垒局部溶纤；对成纤维细胞进行普通接敌攻击，不把胶原等同于纤维蛋白。详细阶段、技能中断边界与来源见 [首领设计](BOSS_STREPTOCOCCUS_DISCUSSION_2026-10-29.md)。坚持基础路线现已纳入本章目标，但双路线、塑形与 Boss 均未实现。

新地图先按 15×11 做布局验证，保持暖棕描边、低对比粉紫地面、米白组织膜、桃粉 / 杏色周边与青绿核心；矩形组织岛、工整周边，纹理不表示放置格。详见 [2026-10-27 画风与尺寸约定](../Art/MAP_STYLE_AND_LARGE_MAP_2026-10-27.md)。30×22 大地图保持独立试绘，不自动接入本章。

每张图至少有两种有意义的防守方案；先核对基础路线、动态路线、射程和后备距离，再绘正式背景。已有第三章预览图需评估复用，不能沿旧炎症地形直接假设新流程可玩；本次不改预览名称或图片。

## 4. 3-1 重塑防线：让改路产生看得见的收益

**空间：** 左侧一个伤口、右侧核心，中间一块偏矩形组织岛，上下两条可达通道。前段空地便于观察分流，中后段各有交战格和侧翼火力位，核心前有第二道拦截距离。

基础路线先走其中一路；塑形后能选择引向另一侧，但每一侧都有自己的火力覆盖条件。较长一路不同时拥有最佳共享支援、最大建造面和最长补救距离，避免“永远选最长路”成为标准答案。

| 波 | 敌人和节奏 | 玩家操作与观察 |
|---|---|---|
| ① | 少量分散基础菌 | 认识原路线，先建近卫等基础火力，不同时教学改路 |
| ② | 基础菌小群 | 开放成纤维细胞，预览路线后塑形；至少留下一个能看懂的有效替代摆法 |
| ③ | 密集基础菌分组 | 壁垒和酸区在选定交战点清群，展示路线安排的收益 |
| ④ | 基础群夹少量已见高速菌 | 补后备拦截或改变投入，检验阵地而非只看空走时间；本关不出先导怪 / Boss |

**验证：** 改路后玩家确实改变了输出覆盖与接敌位置；上下两种摆法都有机会，不改路也可通过更高防守投入应对。开局预算须能建立基本防线并买一座塑形细胞，不能靠未计入规则的免费满阵容证明可玩。

## 5. 3-2 协同清除：一处支援中心还是两套防线

**空间：** 左上 / 左下两伤口，右侧核心。错开的矩形组织岛使两路在中后段靠近，中央留一片有限共享支援区；更靠入口的侧翼能提前输出，但两路较难共享。保留各自有效的壁垒位与核心前补救区。

共享区最多形成一组清楚的辅助 T—巨噬配合，不能在同一小片空地同时获得全部塔的最佳覆盖。主路适合连续吞噬，次路可用范围火力或独立巨噬；塑形可帮助集中交战位置，但本关先不加入拆障。

| 波 | 敌人和节奏 | 玩家操作与观察 |
|---|---|---|
| ① | 主路基础菌与少量高速菌，分散到来 | 用已学近卫—B—巨噬链观察吞噬与消化，预留辅助 T 位置 |
| ② | 相近构成，组间到达更连续 | 开放辅助 T，看见消化恢复变快；标记保障目标有可吞噬窗口，不把目标生命设计得始终不可吞噬 |
| ③ | 次路少量基础 / 高速错峰进入 | 选择分一组支援，还是次路用酸区 / 独立输出；不要求单座辅助 T 包全图 |
| ④ | 两路中等数量混编，主路有停顿供重建 | 比较集中协同和多建独立单位，修正覆盖；不是继续无间断加量 |
| ⑤ | 两路基础群和少量高速先后到达 | 主路吞噬链连续工作、次路清群收尾；不以 Boss、吞噬免疫或护盾怪否定本关新塔 |

**验证：** 同等资源下辅助 T 在合适布局中可节省前线投入，但分散地图中不是必买。记录实际成功吞噬、消化等待与突破情况；若玩家看不见收益或始终不如再买巨噬，应先调整作用与费用，不靠教程强制购买。

## 6. 3-3 防线缺口：保护自己创造的路线

**空间：** 左侧主伤口，偏右核心，组织岛两侧形成短基础路线和可用绕行路线；绕行交战区与基础路线相邻，侧翼可共同覆盖一部分，但完整保护两边需要投入。后半段次入口以少量已见敌人施压，不贴核心突然生成。

先导怪基础路线上的塑形细胞需留可防守侧翼，后方另有壁垒位。图中显示普通路线与“坚持原路”路线，结合线型、图标与入口预告辨识，不能只靠两种颜色。

| 波 | 敌人和节奏 | 玩家操作与观察 |
|---|---|---|
| ① | 主路基础群 | 复习塑形、绕行与清群，玩家先看到阵地正常工作 |
| ② | 单只先导怪，少量或无护卫 | 单独预告其原路线，观察攻击塑形对象 / 壁垒；其伤害和到达时间允许补火力，不固定脚本摧毁玩家单位 |
| ③ | 普通基础群先出，先导怪稍后跟进 | 在绕行区清群与保护改路点间分资源；先导怪数量少，以职责改变制造压力 |
| ④ | 次路少量高速，主路小群，中等以下总量 | 检验后备拦截，留资源调整；不在此时再教重甲或新抗原 |
| ⑤ | 主路成团基础菌与间隔先导怪，次路有限牵制 | 可以维持塑形点，也可以主动放弃，靠后备防线处理被打通的路；无 Boss |

**验证：** 先导怪可被有效攻击；保护改路点值得投入；塑形对象被摧毁后仍能补救。玩家不使用塑形时，先导怪依然是可处理的普通来敌，不额外生成不可避免的伤害。无需塑形的解法应付出火力与空间成本。

## 7. 3-4 溶纤先导：守住与重建都能赢

**空间：** 左侧主伤口、下侧次伤口，核心偏右后。主路有较长绕行区、原路改路点与前后两段防守位置；次路在后段接近主路，可共享一部分支援。两路不在核心前一格才汇合，留明确反应空间。

Boss 固定由主伤口入场，基础路线经过可用的塑形 / 拦截位置，必须有输出能接触它；不把目标藏在无法射到的地形背后。前段能保护塑形点，后段适合集中打 Boss，但失去部分攻击时间。辅助 T 服务普通护卫处理，补体与标记负责持续首领输出，不要求巨噬吞噬 Boss。

| 波 | 敌人和节奏 | 玩家操作与观察 |
|---|---|---|
| ① | 主路基础群 | 建立塑形、接敌与清群关系，不要求开局买齐全部阵容 |
| ② | 次路基础加少量高速 | 分配第二处火力，主路仍保留基础覆盖 |
| ③ | 主路少量重甲与基础菌 | 复用酸化破壳，不再把“酸炮”等同于只清小怪 |
| ④ | 先导怪与基础群错峰 | 复习原路压力，检验塑形点保护与后备墙 |
| ⑤ | 降低总量的基础 / 高速波 | 给修墙、增补单体和检查支援范围的机会，提示末波 Boss 的纤维蛋白目标 |
| ⑥ | 已见混编的中等压力，少量先导怪 | 检验防线是否能在正常投入下持续运作；为章末保留资源和修补额度，不要求先打一轮等强度高潮 |
| ⑦ | 一名溶纤先导由主路进入，前后有限基础护卫；次路仅少量牵制 | 看见局部溶纤预警，选择修补前墙、增加火力或投入后备；半血后技能更频繁，普通群仍能被 AOE 清除形成收尾 |

如缩为六波，应合并第五 / 六波并重算收入与敌量，不移除轻量调整机会。首次 Boss 不同时叠加生物膜治疗、病毒换抗原、炎症或额外真菌 Boss。护卫来自计划波次，不新增首领召唤技能。

**验证：** 前线维持、后方集中至少形成两种可行投入；不依赖手动锁定 Boss、不要求极快卖塔补塔；修补有价值但不无限续命；Boss 的溶纤不会误伤非纤维蛋白目标。总时长与同屏峰值靠实际试玩标定，不仅检查可达与自动通关。

## 8. 第四章衔接：免疫平衡，待炎症原型通过

原第三章炎症规则顺延：来源存在时积累，适度激活可有收益，过热先预警再缓慢伤害区内防御细胞；清源后恢复。普通攻击和击杀不自动涨条，不加尸体积累。Treg、炎症敌人、区域 UI 均未实现。

| 暂定关卡 / 波数 | 地图、敌人和流程草案 | 新内容与取舍 |
|---|---|---|
| 4-1 充血边缘 / 4 | 单入口单区域；①少量来源加基础菌观察状态，②区内外布防比较，③温和预警后清源，④无来源的基础波观察恢复 | 只教炎症，不加新塔；区外能攻击来源，过热后仍可补救 |
| 4-2 反应交汇 / 5 | 两路靠近，一路经过炎症区；①已见普通群，②单路来源，③次路高速，④较轻调整，⑤两路错峰混编 | 辅助 T 已解锁，考验共享支援和塑形能否把交战点安排到区内或区外；来源离区停止影响，不因改路产生无上限永久加压 |
| 4-3 过热前沿 / 5 | 主路优质交战位在区域内，后方安全位较分散；①复习来源，②展示调节，③持续压力，④无来源恢复，⑤来源加已见混编 | 新增 Treg，降温与失去部分适度激活收益并存；清源 / 后置也能赢，Treg 不修墙或回血 |
| 4-4 双灶组织 / 约 7 | 左右两个不重叠区域；前段分别施压，中段错峰轮换，轻量波重建，末段来源先到、后跟一名已见真菌 Boss 与有限普通群 | 利用与稳定两区，已有塑形 / 辅助 T 参与但不强制购买全部支援；不再加入新 Boss 规则 |

本表只确定衔接方向，详细空间原则由原炎症方案迁移，关数与首领可调整。先做 4-1 单图；若炎症只剩盯条或惩罚清群，缩减或延期，不为填满章节而保留。

## 9. 第五章与制作顺序

第五章留“细胞内感染”方向：先在一个小规模遭遇里展示可辨识的感染宿主及有预告的产敌，再选择 NK / CD8 中一种清源单位验证，最后才考虑多感染点与正式关数。感染宿主不同于游离病毒粒子，当前病毒母体不能改名当成完成。嗜酸性粒细胞与寄生虫仍不排近期关卡。

制作顺序：

1. 验证一格塑形、每入口基础路线 / 普通动态路线、预览和建造合法性；复用旧代码前先核对接口，保持现有壁垒不改路。
2. 完成 3-1 布局和小规模经济试玩；收益若仅为空走更久，先改地图，不继续堆关数。
3. 用 3-2 验证辅助 T 与巨噬收益，再以 3-3 验证原路先导怪和失守后的补救。
4. 单独验证首领局部溶纤，再接入 3-4 综合；确认目标、暂停、阶段、死亡 / 出售及伤害边界。
5. 第三章验收后再更新章节目录、解锁与预览内容，保留旧成绩；再开始第四章炎症单图。

本次只完成文档。未来程序接入测试需覆盖双路线和失败建造不扣费、塑形生死后的路径连续性、支援失效、首领施法、评分和已有九关回归；这些测试当前未运行，后续需求不能写成已完成结果。
