# 新单位首次介绍卡与图鉴收录

> 设计稿 v0.1 · 2026-10-29；配套策划 v0.32。用户同意将首次认识细胞、区分人体作用 / 游戏功能、随后收录图鉴的流程写入策划。本次仅更新文档，未新增卡片、图片、存档状态或战斗功能；制作时间与逐单位文案待定。

## 1. 目标与现有基础

解锁新单位时，让玩家依次理解“它是谁、现实中做什么、在游戏中怎样使用”，再通过实战验证。图鉴承接随时复查，不把整套战斗教学压到一张卡片里。

项目已有主菜单“细胞图鉴”入口、免疫防线 / 入侵者分类和同类翻页。现有素材文档记录了六种防御单位与八种敌人的 14 个条目，主要介绍属性、战斗特性、使用 / 应对建议；其中固定属性图片为 2026-10-28 配置快照。详见 [现有图鉴说明](../Art/CELL_CODEX_2026-10-28.md)。

这批素材和入口可复用，但不代表已具有首次解锁弹卡、真实作用分栏、收录 / 已读状态或战斗内查阅。本方案需补充这些能力，并核对第二、三章新单位的条目覆盖与旧数值；不把旧图鉴测试当成新流程验收。

## 2. 首次卡片的固定内容

| 内容 | 首次卡展示 | 目的 |
|---|---|---|
| 名称、立绘、类型标签 | 一眼能认出单位 | 建立身份，不仅记住塔图标 |
| 在人体中 | 一至两句真实作用 | 认识原型，不堆专业术语 |
| 在游戏中 | 一至两句核心功能，包含关键限制 | 知道可以用它解决什么问题 |
| 布置 / 使用建议 | 一条最相关建议 | 引导本关尝试，不给唯一标准塔位 |
| 操作 | “开始使用”“查看图鉴” | 继续战斗或主动阅读详情 |

卡片不罗列全部伤害、射程和倍率，也不连续叠多页强制阅读。真实作用与游戏功能必须有明确分栏标题；不能只依靠颜色区分。简短文字允许立即关闭，不设强制阅读倒计时。

“开始使用”表示关闭介绍并返回本局，不免费建造、不自动扣费、不替玩家开波。可在返回时提示新单位的选塔位置，但不强制购买。

## 3. 触发、暂停与重试

1. 单位首次开放时，在该关第一波开始前介绍，不等玩家花钱建造后才说明功能。
2. 若设计为关中开放，在开放事件发生后、敌群重大预告之前展示；战斗、出怪、自动开波倒计时和临时状态一起暂停，不能让玩家读卡时失去防线。
3. 展示首次卡时收录对应图鉴条目，并标为“新”；介绍是否已看过与图鉴的新标识分别记录，关闭卡片不等于已经阅读图鉴详情。
4. 点“开始使用”或直接关闭 / 跳过均算本次介绍已确认；确认后保存状态。重试、重进关卡或重新启动不再强制弹同一张卡，但保留主动重看入口。
5. 从首次卡进入“查看图鉴”时保持暂停；退出详情回到卡片或原返回层级，不在图鉴打开时恢复战斗。退出整个介绍流程后恢复此前暂停状态与倍率；玩家此前手动暂停的局仍保持暂停。

多单位同时开放时，按当前教学重点逐个介绍，每次只一张卡，不叠窗；优先通过关卡安排避免第一次就集中开放大量单位。与已有第一关提示、下一波预告、设置和结算协调，终局不再弹解锁介绍，重开不携带旧局弹窗。

## 4. 图鉴详情与收录规则

图鉴详情比首次卡多一层信息：

- 人体作用与原型来源。
- 游戏定位、技能、关键限制及基础属性。
- 与其他单位的配合、适合位置及应对建议。
- 哪些属于游戏改编，例如即时塑形、冷却、伤害、吞噬阈值与范围。

主菜单入口保留；未来选塔或单位说明处提供主动查看 / 重看，战斗内阅读遵循同一暂停规则。首次卡与图鉴的名称、能力和基础属性应保持一致，当前值以实现配置为准；平衡改动后需同步文案与固定属性图片，不能用旧图鉴数值解释新能力。

收录状态服务认识和复查，不改变战斗解锁条件、三星要求或既有关卡成绩。已有图鉴可访问内容不因新增收录系统重新隐藏或收回；存量玩家迁移时保留访问，首次介绍状态的补齐方式待实现确认，不集中补弹所有旧卡。

未制作的机制候选不自动进入正式可用图鉴，不因入库而显示成已解锁。若以后增加未知剪影或收集进度，需要另定规则，本次不要求把现有目录改为锁定目录。

## 5. 类型标签与生物文案边界

| 示例 | 标签方向 |
|---|---|
| 中性粒、巨噬、B、辅助 T | 免疫细胞 |
| 成纤维、潘氏 | 组织细胞，并补充更具体身份 |
| 纤维蛋白、补体 | 蛋白质 / 防御物质 |
| 溶酶体 | 细胞器 |
| 神经脉冲相关单位 | 神经结构原型 / 游戏化防御单位，具体名称另核对 |

保留“细胞图鉴”入口名，不将其中所有对象写成免疫细胞。单位在真实人体中的比例、位置和作用需有可核对依据，避免从某种微生物的特例推成所有对象通用规则。

成纤维细胞的胶原分泌与伤口修复属于原型说明，“放置后立即使一格不可通行”属于游戏规则；两者分开呈现。辅助 T 的游戏文案按当前实际能力编写，现行版本支持抗体标记，不把此前巨噬支援候选写成已实现。生物科普提及清除死亡细胞，也不表示尸体回收玩法已启用。

## 6. 巨噬细胞首次卡文案示例（待文案与视觉验收）

**巨噬细胞**

类型：免疫细胞

**在人体中**

吞噬病原体，清除死亡细胞及碎片，参与维持组织环境。

**在游戏中**

能吞噬符合条件的残血敌人；抗体标记会提高可吞噬的生命门槛。吞噬后需要时间消化，无法吞噬首领。

**布置建议**

放在火力覆盖的交战点或防线后方，接住被削弱的敌人。

**开始使用　｜　查看图鉴**

示例不新增技能，护盾等完整限制与具体属性放在图鉴详情。人体说明需在正式发布前核对；尸体清除原型可参考[巨噬细胞胞葬与组织恢复研究](https://www.nature.com/articles/s42255-024-01115-7)。

## 7. 入侵者的同类扩展

以后可在新敌人首次出现前，以同一结构介绍“真实特点—游戏威胁—应对建议”，实际遇到后收录入侵者条目；未实际出场的计划敌人不因查看预告自动计为遭遇。已有可访问条目仍保留。

首领预告与首次介绍整合，避免同一次登场重复弹多张卡；玩家读介绍时冻结战斗及自动开波。此项属于后续扩展，不自动决定候选怪物的出场时间。

## 8. 接入顺序与验证目标

建议先用一个已有单位验证卡片内容、退出与图鉴跳转，再扩充其他已开放单位；不以一次重做全部图鉴美术为前提。保持当前像素美术与手机可读性，图片最终交付仍使用项目约定素材目录，保留旧版及 `.meta`。本次不生成图片。

后续验收应覆盖：首次开放弹一次、退出后重试不重复、图鉴新标识与介绍状态分离、暂停 / 倍速 / 自动开波恢复正确、图鉴往返不穿透输入、存量用户访问不丢失、已有引导和终局不冲突、人体与游戏功能不混写，以及不同屏幕下文字可读。

当前没有该新流程的运行、存档迁移或视觉验收证据。本稿不改变单位加入时机、章节顺序、候选库排期或现有十三关。
