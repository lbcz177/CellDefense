# 纤维蛋白承伤壁垒

日期：2026-10-20；策划 v0.22。用户授权将现有改路墙先改成“坚果式”拦截，随后明确取消改路限制，并要求保留旧代码供未来复用但不显示。

## 当前规则

- 沿用现有纤维蛋白素材、Prefab 和共享 Definition 引用；30 ATP、500 生命为本次试验配置。
- 路线由固定地形决定；全部可建单位不改变寻路。壁垒只拦经过自身位置并进入接敌范围的敌人，不吸引其他通道、不拉回已经越过的单位。
- 壁垒拦截人数无上限，每个被拦敌人都按自身攻击间隔造成伤害。普通怪 10 / 秒、Boss 25 / 秒；首次攻击等待完整间隔，停顿 / 暂停规则沿用。
- 取消累计 6 座、封路拒建和敌人当前 / 下一格改路保护规则；建造仍检查 ATP、有效格、核心 / 入口 / 地形与已有占位。当前存在敌人的格子不再仅因旧改路规则被禁止，但不会将已经走过接敌点的敌人拉回。
- 普通细胞仍 100 生命 / 容量 1，巨噬 250 / 2；它们的溢出通行规则不变。
- 壁垒破裂或出售，立即释放全部接敌、占用、邻接和光环，敌人沿原路径前进。死亡无退款，出售返实付金额 50% 向下取整；有效空格可再次建造。
- 保留原有 40% 减速光环，不新增伤害、修理、移动、队列避让或壁垒升级。

## 旧改路代码的保留范围

OpenFieldGridModel 的道路阻挡、BFS、临时可达性检查及改路预览，控制器的 CheckLegacyRoutePlacement / RebuildAssaultRoutes，以及 PathFollower.Reroute 均保留。BlocksEnemyRoute 字段隐藏，当前纤维蛋白为 false。

当前建造 / 出售 / 死亡不调用改路算法；选塔、属性、HUD、出售确认和策划配置工具不显示改路或额度选项。基础地形路线仍可帮助布置，旧黄色候选改路线不启用。未来“大蒜式”单位只保留为设计方向，没有增加该单位或新图像。

## 验证与发布边界

行为验证包括：八名敌人全部接敌并共同伤害、破裂 / 出售释放、暂停保持、普通细胞溢出、超过六次建造和死亡后补建、唯一通道可布置、路线 / 生命 / 入场版本保持，以及既有五关回归。

测试在已有隔离 Unity 工程运行，结果见 [本次报告](Testing/2026-10-20_FibrinBarrier.md)。500 生命的难度和完整五关通关仍需用户试玩。

本次只修改本地工程和文档，不重新构建 APK、不修改 TapTap。已有 Android 0.1.2 / Code 3 及远程草稿仍是旧玩法，不能用来验证本次壁垒。
