# 胜利与失败界面的屏幕适配

日期：2026-10-21；适用于五个 OpenField 关卡。

原预制体使用固定像素 Canvas，背景局部缩放为 10，按钮为 6；已有缩放修正只在手机模式下执行。桌面 640×480 窗口中，背景左边界为 -180，标题和下方按钮超出屏幕。

现由 OpenFieldPrototypeController.FitResultToScreen 在两端统一处理：背景恢复单位缩放并设置为 600×600，按钮恢复单位缩放并按 512×96 重新排布；整组内容通过现有 MobileSafeFrame 在 800×720 设计区域内等比适配安全区。上下保留空白，窗口变化时通过 Canvas.preWillRenderCanvases 重新计算。

胜利页仍按关卡显示下一关 / 重试 / 返回；第五关胜利和失败页为两按钮布局。原图片、Prefab、GUID、场景引用与按钮回调不改写。仅改变运行时布局。

Unity 完成编译后重新运行或重载关卡，新的初始化布局生效。既有 APK 不会自动更新。本次验证及实际渲染见 [修复报告](Testing/2026-10-21_ResultLayout.md)。
