# 开始界面细胞流动

后续已新增紫色细菌独立重绘与通道动画，运行时背景换为清理过的通道底图，见 [紫色细菌重绘与流动](MAIN_MENU_BACTERIA_REDRAW_2026-10-28.md)。本文记录白细胞局部漂移的实现及其优化过程。

蓝色防御细胞后续增加粒子发射、抗体飞行、吞噬碎屑和细胞核轻微亮度变化，见 [蓝色防御动效](MAIN_MENU_BLUE_DEFENSE_2026-10-28.md)。

开始界面的标题、按钮和细胞原本烘焙在一张像素图中。本次对原图增加局部 UV 动画：四颗大细胞缓慢小幅漂移。根据用户反馈，最终版本去掉第一版的细胞呼吸缩放与中央通道扭曲，以较宽的平坦内遮罩整体平移细胞，外围组织再平滑过渡。左侧按钮、完整标题和画面外沿保持固定；不替换原 PNG、Sprite 或场景引用。

`MainMenuController` 在创建叠层界面前自动为背景添加 `MainMenuCellFlow`。它实例化 `Resources/MainMenuCellFlow.mat`，使用 `Art/Shaders/MainMenuCellFlow.shader`，使 Shader 通过资源材质保留在构建中。动画使用非缩放时间；偏移约 4 个原图像素，周期 5.4 秒，无缩放。仅运动区域使用四点采样插值来减轻 Point 贴图的整像素跳动；静止区域仍采样原图，原材质和纹理导入设置不变。组件销毁时释放独立材质，不修改共享资源。

本次为局部流动效果，细胞并未拆分成独立角色，也不会跨越整张界面移动。点击热区、选章流程和设置逻辑没有调整。

验证：Unity 2022.3.53f1c1、D3D11、Android 目标的隔离项目。主菜单动态渲染测试和既有设置／退出测试共 4 项通过。新测试在 1280×720、640×480、2048×928 比较两个动画时刻的真实渲染，确认细胞区域像素发生变化、左侧按钮／标题像素完全相同，并确认动画在非缩放时间下继续推进。额外导出桌面尺寸采样帧用于动态预览，复核该测试通过。

第一版截图和低帧率 GIF 保留在 `Assets/_Project/Art/Sprites/细胞绘制/开始界面流动_2026-10-28_v1/验证~/`，作为历史记录。第一版预览为每帧 0.4 秒（2.5 FPS）并倒放；游戏本身一直逐帧更新。

优化版预览位于 `Assets/_Project/Art/Sprites/细胞绘制/开始界面流动_2026-10-28_v2/验证~/`，采样完整 5.4 秒周期共 180 帧，每帧 0.03 秒（约 33.3 FPS），只正向循环，没有倒放接缝。此 GIF 是 Unity 实际 Shader 渲染采样，不作为游戏运行素材，也不代表设备性能测量。移动端原有 60 FPS 目标不变，实际帧率取决于设备。

优化版重新核对三种分辨率的细胞移动、左侧和完整标题静止、非缩放时间以及既有开始／设置／退出交互，共 4 项测试通过，报告保存为 `Docs/Testing/2026-10-28_MainMenuCellFlow_v2_playmode.xml`。第一版报告 `2026-10-28_MainMenuCellFlow_playmode.xml` 与 `2026-10-28_MainMenuCellFlow_capture.xml` 保留。未构建 APK 或修改发布资料。
