# 教程与战斗提示图片化（2026-10-21）

当前五关与选关页中仍使用原始字体显示的提示，已改为预绘制 PNG 文案或像素字图。素材直接保存在 `Assets/_Project/Art/Sprites/细胞绘制/提示图片化_2026-10-21_v1/`。

## 覆盖范围

- 第一关全部引导阶段、进度、自由操作说明、跳过与继续按钮。
- 八种敌人的首次出场说明及对应单位肖像。
- Boss 名称、阶段 / 技能预告、护甲破除、病毒抗原状态。
- 敌人与己方细胞的生命、拦截 / 接敌说明。
- 入口波次及提前开始说明、顶部壁垒规则提示。
- 建造菜单的名称、价格、职责、拒建原因与取消提示。
- 塔详情、升级状态、出售返还与二次确认。
- 选关标题、关卡名、操作提示与返回按钮。

旧固定路线参考场景 `Prototype` / `Level02` 的历史 `HudController` 不属于当前五关主线。本轮不修改其历史界面。

## 制作与接入

交付 96 条固定文案切片、449 个字符的 12px / 8px 两套字图、四张面板 / 按钮图。固定文案与字形收录在三张图集中，避免每个字创建 GameObject 或单独纹理。

`PixelImageText` 直接绘制图片四边形：能按预设版式容纳固定文案时使用完整文案图片；数值、名称组合或窄区域需要重排时，使用像素字图拼接。文字仍由原玩法状态提供，因此价格、生命、波次与教程进度保持实时更新。它不调用 Font、TMP 字体渲染或动态字体图集。

按实际屏幕字号切换 12px / 8px 字图，并保持最小原生像素大小，避免 640×480 小窗口缩图丢笔画。建造卡片增加文字空间，使名称、价格和拦截职责能完整显示。

教程仍可跳过、不暂停战斗，也不改变 ATP、出怪、伤害或过关条件。增加了正文空间，保留安全区定位与菜单避让。怪物出场卡增加单位肖像，桌面和手机均放在右上暂停 / 倍速按钮下方。

运行时入口：

- `Assets/_Project/Scripts/UI/PromptImageResources.cs`：文案、字图、面板和按钮的资源索引。
- `Assets/_Project/Scripts/UI/PixelImageText.cs`：图片绘制、换行、对齐与尺寸适配。
- `Assets/_Project/Resources/PromptImageResources.asset`：主项目直接使用的资源配置。
- `OpenFieldBattleHud.prefab`：规则提示组件保留原 local fileID，更换为图片组件，五个场景的已有 HUD 引用继续有效。

旧美术及其 `.meta` 保留；此前工作区已经存在的教程、结算布局等修改没有回退。旧字体资源与部分方法的字体参数保留用于历史工具兼容；当前上述提示的可见控件使用图片。

## 画风与源文件

沿用珊瑚色边框、墨紫底色、青色内缘与奶油色文字。怪物出场面板使用紫色边框及金色内缘，以区分普通操作引导。

空白提示面板由内置 imagegen 绘制；Aseprite 清理色板、透明边缘及中心区域，制作九宫格面板、按钮和文案图片。完整中文文案采用离线像素字形制作，避免长句生成出现错字；运行时使用 PNG。

字形源为 [Fusion Pixel 8px / 12px Monospaced 简体中文，官方 2026.09.01 发行版](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01)，其字体采用 [SIL Open Font License 1.1](https://github.com/TakWolf/fusion-pixel-font/blob/master/LICENSE-OFL)。未修改的源文件和随发行版提供的许可证保存在素材的 `制作记录~/字形来源/`，不会导入运行时。

`制作记录~/` 另存原始绘图、逐条文案 PNG、文案图集与面板的 `.aseprite` 源文件、绘制 Lua、处理清单及接入前八个文件的备份。制作脚本工作入口位于 `Logs/PromptArtwork20261021/`；若新增提示出现未收录字符，需补充字图并重新导出，不能仅替换原字体。
