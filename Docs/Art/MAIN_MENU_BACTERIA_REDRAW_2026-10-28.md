# 主菜单紫色细菌重绘与通道流动

用户希望紫色细菌沿通道移动，并明确要求重新绘制完整素材。本次使用内置 imagegen 新画一组球形、杆状、小球形紫色微生物，再由 Aseprite 导出三张独立的 128×128 RGBA Sprite。运行时不再使用从场景截出的细菌。透明边缘统一处理，全部外轮廓与突起位于画布内，保留至少五像素透明边距。

最终素材位于 `Assets/_Project/Art/Sprites/细胞绘制/紫色细菌重绘_2026-10-28_v3/`：三张重绘 PNG、清理通道后的菜单背景、四份 Aseprite 源文件、生成原图、完整提示词与导出脚本。旧的切图版本和 `.meta` 保留；`MainMenuBacteriaArtwork.asset` 保留原 GUID，背景及三个细菌引用已指向新素材，替换前资源配置保存在 `制作记录~/`。

背景的空通道由 imagegen 补画，Aseprite 仅替换通道范围内紫色像素，保留原图按钮、标题和白细胞等前景。白细胞嘴里的紫色微生物仍属于该前景角色，没有作为流动细菌提取。

`MainMenuBacteriaFlow` 创建十个不接收点击的独立 UI Image，沿右上伤口到左下的 Catmull-Rom 通道曲线运动。三类细菌使用不同尺寸、轻微错速和横向错位；杆状细菌跟随切线，球形细菌缓慢旋转，身体尺寸不随时间变化。开始和结束均淡入淡出，并在接近左侧按钮区域前完全隐去。使用非缩放时间逐帧更新，不依赖 GIF 播放。

验证使用 Unity 2022.3.53f1c1、D3D11、Android 构建目标的隔离项目。增强的主菜单渲染测试确认三个运行 Sprite 都是重绘版、十个细菌均随时间前进、尺寸保持不变、不拦截鼠标，且标题和按钮固定。1280×720、640×480、2048×928 三种尺寸验证与既有开始／设置／退出交互共 **4 项通过**，报告在 `Docs/Testing/2026-10-28_MainMenuBacteriaRedraw_playmode.xml`。

`验证~/紫色细菌_重绘流动_33fps.gif` 为 Unity 实际采样的 5.4 秒片段，180 帧、每帧 30 毫秒（约 33.3 FPS）。它是预览，不参与运行；重播这个短片段会重置预览，而游戏内是每颗细菌在透明端点独立循环。没有构建 APK、变更旧关卡或修改平台发布内容。
