# 主菜单蓝色防御细胞动效

在保留紫色细菌通道流动的基础上，为蓝色防御细胞增加动作反馈：树突细胞和中性粒细胞向通道发射小型青蓝像素粒子；右侧细胞向细菌方向释放黄色 Y 形抗体；大吞噬细胞口部有向内收拢、逐渐缩小的紫色碎屑。四颗防御细胞的细胞核还会错相轻微亮起。

本次采用行为粒子与亮度变化，不增加身体拉伸、挤压或通道扭曲。原有整颗细胞微幅漂移仍保留；嘴部和触手不做骨骼形变。所有原图和已有 `.meta` 保留，无需重新裁切蓝色细胞。

`MainMenuDefenseEffects` 是独立的 `MaskableGraphic`，由 `MainMenuCellFlow.Attach` 在背景子级创建。小方形粒子与 Y 形抗体通过 UI Mesh 绘制，按时间插值位置和透明度，不依赖新位图。该图层关闭 raycast，所有顶点留在右侧防御区，避开菜单按钮。`MainMenuCellFlow.shader` 在局部细胞核区域叠加低强度、平滑的蓝色亮度脉冲。两种动画均逐帧更新，使用非缩放时间。

验证使用 Unity 2022.3.53f1c1、D3D11、Android 目标的隔离项目。增强主菜单渲染测试检查粒子网格随时间移动、右侧范围约束及不拦截点击，并继续验证重绘细菌移动、身体尺寸稳定、标题与按钮不动。1280×720、640×480、2048×928 三种分辨率与既有设置／开始／退出交互共 **4 项测试通过**。报告为 `Docs/Testing/2026-10-28_MainMenuBlueDefense_playmode.xml`。

实际 Unity 截图及动态预览在 `Assets/_Project/Art/Sprites/细胞绘制/蓝色防御动效_2026-10-28_v1/验证~/`。GIF 是 180 帧、每帧 30 毫秒的约 33.3 FPS 渲染采样片段；游戏不读取这个 GIF，实际帧率取决于设备。没有构建 APK、修改战斗玩法或发布内容。
