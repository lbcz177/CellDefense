# 《细胞防卫战》统一美术方向与资产规范

> 视觉代号：**活体图鉴 / Living Field Guide**  
> 文档状态：美术基线 v1.0  
> 视角：2D 横屏俯视  
> 目标：远看像有生命的策略棋盘，近看像一本轻松但可信的细胞图鉴

## 0. 一句话画风

把“显微镜下的细胞世界”处理成轮廓清楚、无血腥、弱阴影的 2D 生物绘本：温暖组织是舞台，冷色免疫单元组成有秩序的信号网络，洋红/紫色病原体以不对称群落侵入，信号和炎症用荧光色成为玩法信息。

这不是写实医疗插画，也不是传统炮塔换成圆球。所有造型都要让玩家看出细胞在“感知、传递、包裹、分解和记忆”。

---

## 1. 视觉支柱

### 1.1 玩法可读性优先

- 缩小到手机上的 48–72 px 时，塔和敌人仍能只看轮廓区分。
- 识别、已标记、群落感应、炎症危险和路线切换必须比装饰更醒目。
- 特效只在发生机制时出现；持续大面积粒子不能遮挡路径或血条。
- 颜色永远与形状、图标、线型至少一种共同编码，不依赖色觉。

### 1.2 有生命但不恶心

- 使用膜泡、细胞核、伪足、纤维、抗体 Y 形和囊泡等抽象生物结构。
- 避免真实伤口、鲜血、内脏、脓液、黏液摄影质感和恐怖寄生虫特写。
- 敌人可以淘气、狡猾或危险，但不做重口恐怖。

### 1.3 科学启发，不冒充教材

- 可以用真实结构作为造型来源，例如中性粒细胞分叶核、巨噬细胞伪足、B 细胞抗体。
- 玩法武器化、神经电弧和信号图都是艺术改编；图鉴要明确标注。
- 宣传图不要使用“真实治愈”“医学模拟”等误导性表述。

### 1.4 同一世界

- 防御方：圆形、包裹、对称、放射、柔和曲线。
- 病原方：尖刺、偏心、不对称、裂缝、簇状重复。
- 组织：大块柔软曲线和半透明层，不抢角色轮廓。
- 信号：细而清晰的荧光线，像神经/细胞因子网络，不像科幻激光网。

## 2. 镜头、比例与构图

### 2.1 游戏内视角

- 地图背景：正交俯视，接近 90°，不能有明显透视消失点。
- 塔与敌人：伪俯视 70–75°，露出约 15–20° 侧面，方便显示细胞核和表情。
- 光源：统一来自左上方；只使用 2–3 档色块明暗。
- 接地：角色下方使用短小、低透明度椭圆接触影；无长投影。
- 朝向：需要朝向的塔默认朝右上；最终在 Unity 中旋转炮口/子节点，不生成八套不一致本体。

### 2.2 尺度

这是可读性尺度，不代表真实生物尺寸：

| 资产 | 游戏内建议直径/长度 | 备注 |
|---|---:|---|
| 普通敌人 | 42–56 px | 高速敌人偏小、重甲偏大 |
| Boss | 120–180 px | 不超过可玩区域短边约 18% |
| 塔主体 | 76–104 px | 六塔占地接近，轮廓差异来自结构 |
| 投射物 | 8–24 px | 高频曳光可更细，但必须高对比 |
| 状态图标 | 24–32 px | 手机上可辨，避免细节过多 |
| 信号线 | 3–6 px | 根据缩放保持最小屏幕宽度 |

### 2.3 安全构图

- 游戏精灵单体居中，四周至少留 12% 透明边距。
- 塔的接地点位于画布中心下方约 40%，便于 Pivot 统一。
- 敌人尾巴/鞭毛不能越过画布太远，否则 Atlas 空白浪费大。
- 地图预留顶部 HUD、底部塔栏和手机 Safe Area，重要路线不贴边。
- AI 概念图与生产精灵分开生成；带漂亮背景的概念图不能直接当透明精灵。

### 3.2 色彩规则

- 防御方即使换塔色，也保留青/白膜边或蓝色核心，维持阵营一致。
- 敌人即使出现绿色/黄色能力，也保留洋红/紫色主体或墨紫尖锐轮廓。
- 已采样永远使用黄绿色碎片/虚线；已标记永远使用金色 Y 形环。
- 炎症从橙到红，并加入脉动边框和警告图标，不能只改变全屏色调。
- 红绿色盲模式下，敌我还依赖圆润/尖锐轮廓、实线/锯齿线和图标。

## 4. 线条、材质与阴影

- 外轮廓为墨紫色，生产精灵在 512 px 源图中约 6–10 px；内部线为外轮廓的 50–70%。
- 使用柔和手绘不规则感，但不能毛糙到缩小时闪烁。
- 每个材质最多：主体色、阴面色、高光色、少量半透明结构。
- 细胞膜允许一圈轻微半透明；不要使用写实折射、玻璃球或强 3D 塑料高光。
- 不使用复杂环境光、电影景深、镜头光晕和长阴影。
- 纹理只用于非常轻的纸感/细胞颗粒，强度低于 8%，不能干扰玩法信息。

## 7. 地图与 UI 风格

### 7.1 地图

- 路径是组织天然结构，如创口沟槽、胶原间隙和血管流线，不画成石砖道路。
- 固定塔位是自然的细胞附着点/组织节点，不画成传统圆形炮塔底座。
- 信号边嵌在组织纹理中，空闲时低对比，样本经过时才发光。
- 背景装饰使用大形，不放大量与敌人同尺寸的圆点。
- 每关主色不同，但保持同一轮廓、材质和信号系统。

### 7.2 UI

- 面板像半透明显微镜载玻片/生物图鉴卡，而不是军事金属 HUD。
- 圆角矩形、柔和墨紫轮廓、纸感轻纹理；高亮使用青和金。
- 图标先做黑白剪影测试，再加色。
- 数字采用清晰无衬线字体；科普标题可配少量手绘字体，但正文不能牺牲阅读。
- 科普卡明确显示标签：“真实知识”“简化表达”“玩法改编”。

## 8. 资产生产规格

### 8.1 AI 输出建议

| 类型 | 源图建议 | 背景 | 比例 |
|---|---:|---|---|
| 单体塔/敌人概念 | 1024×1024 或更高 | 浅灰/透明候选 | 1:1 |
| 生产精灵候选 | 1024×1024 | 纯透明或纯色抠图底 | 1:1 |
| 投射物/VFX 单帧 | 512×512 | 透明 | 1:1 |
| 状态/UI 图标 | 512×512 | 透明 | 1:1 |
| 地图背景 | 4096×2304 或 2048×1152 | 完整画布 | 16:9 |
| 宣传主视觉 | 3840×2160 | 完整场景 | 16:9 |

AI 工具的透明背景并不总可靠。保留纯色底版本，抠图后检查半透明边缘、孔洞和脏色。

### 8.2 Unity 导入前处理

- 保留原始生成图、提示词、模型/服务、日期和许可记录。
- 在外部工具中清理轮廓、统一色板、修正对称/肢体/细胞结构。
- 同类精灵裁到一致画布与接地点；导出无额外透明边缘的 PNG。
- 最终源图按需要缩到 256/512/1024，不直接把 4K 单体全部塞进运行时。
- 同类资产进入 Sprite Atlas；法线贴图首版不需要。
- 先用最小目标尺寸检查，再在 Inspector 中确认 Filter、Compression、Max Size、Pivot 和 PPU。
- 动画帧必须在相同画布、Pivot 和体积下清理，避免 AI 每帧结构漂移。

## 9. 动画原则

- Idle：4–8 帧或轻微程序化呼吸；幅度不超过主体 4%。
- 攻击：先有 100–180 ms 蓄力方向，再有短促释放；高射速塔不每发播放完整夸张动画。
- 受击：轮廓闪白/压缩 60–100 ms，避免持续抖动。
- 死亡/清除：向内收缩、膜泡分解、碎片回收；不表现血液喷溅。
- 群落行为以整组同步节拍表达，但给成员加入少量相位差，避免机械复制。
- Boss 阶段变化保留体积和识别轮廓，只改变孢子囊、菌丝和发光区域。

AI 不直接承担最终逐帧动画的一致性。优先生成关键姿势或部件分层，再由 Animator、骨骼/变形或人工补帧实现。

## 11. AI 资产工作流与验收

```text
玩法轮廓说明
 -> 每类 4–8 张黑白/低色概念
 -> 只选 1 个轮廓方向
 -> 同色板精修
 -> 生成生产精灵候选
 -> 人工抠图/纠错/统一 Pivot
 -> 48–72 px 游戏场景测试
 -> 状态、受击和技能覆盖测试
 -> 记录来源和许可
 -> 进入 Atlas/Prefab
```

每个资产通过以下问题才可替换占位：

- 不看颜色能否分辨阵营和类型？
- 缩小后必须结构是否仍存在？
- 与其他已选资产是否像同一位画师、同一镜头？
- 是否遮挡路径、信号线、血条或塔位？
- 是否包含 AI 常见错误、脏边、文字或水印？
- 许可是否允许当前比赛、作品集和发布用途？
- 科学启发和玩法改编是否在图鉴中正确标注？

## 12. 不采用的视觉方向

- 写实血肉、恐怖伤口和湿润黏液：不适合轻量科普和广泛玩家。
- 传统军事炮塔换皮：无法体现细胞反应链。
- 高饱和霓虹赛博朋克：会让组织、信号和炎症层级混乱。
- 全部无轮廓水彩：缩小后塔与敌人不可读。
- 复杂 3D 拟真细胞：制作成本、移动端性能和美术一致性风险过高。
- 每种塔采用完全不同画风：即使单张好看，也不进入正式资产库。
