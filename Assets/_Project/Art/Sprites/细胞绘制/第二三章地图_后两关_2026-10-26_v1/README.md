每张生产 PNG 旁附同名 `.aseprite`。第二章源文件保留原始地图层；第三章另含可分别关闭的炎症范围图层。3-3 的主前线范围与 3-4 的左／右前线范围各自导出一张透明 PNG，共三张，均与对应基底同画布、同中心 Pivot、同 PPU。它们用于单独叠加，不替换地图背景；3-4 的两个覆盖层可独立显示。总览与 `预览~/` 显示覆盖层，生产基底保持中性地面，不烘焙激活、预警或过热状态。

工具为内置 image_gen，使用前批已确认的 2-1 作为风格参考，Aseprite 导出的 15×11 空间草案作为构图参考；生成后另做位置校正。完整提示词、校正提示词、输入／输出记录及源文件哈希均保存在 `制作记录~/`。Aseprite 用于空间参考、透明范围、原生源文件和总览，生产基底保持最终生成输出的原始像素。

Unity 导入信息为 Sprite / Single、Point、无 mipmap、无压缩，PPU 为原图宽度 ÷ 15。源文件与旧素材保留，各文件使用新 GUID。未修改已有场景、波次、塔或原有美术引用。

静态四邻接检查证明空间草案中每个入口与所有可走格均可到核心，3-4 两路各经过自己的范围且不交叉覆盖。此结果仅对应灰盒；生成图形使用有机轮廓，正式接入时须重新核对图片、固定障碍和实际路径，不能把 PNG 当作寻路数据。范围状态、Treg、补体、入口排程及关卡平衡仍需后续开发与试玩。本批交付地图美术，不代表已经实现可玩章节。
