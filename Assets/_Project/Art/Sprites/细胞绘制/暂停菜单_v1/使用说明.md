# 胞卫战 · 暂停菜单 v1

共 7 张独立透明 PNG：一个空面板，三个按钮各含未选中和选中状态。未选中为奶油色，选中为青蓝色。

| 组件 | 未选中 | 选中 |
| --- | --- | --- |
| 返回游戏 | 02_返回游戏_未选中.png | 03_返回游戏_选中.png |
| 退出到主菜单 | 04_退出到主菜单_未选中.png | 05_退出到主菜单_选中.png |
| 设置 | 06_设置_未选中_v2.png | 07_设置_选中_v2.png |

空面板为 01_空面板.png，内部留白，面板外透明。按钮文字和返回游戏的三角图标已包含在 PNG 中。

导入 Unity 后可将 Texture Type 设为 Sprite (2D and UI)、Sprite Mode 设为 Single，使用 Point 过滤并关闭压缩以保留像素轮廓。在固定 RectTransform 中切换对应 Sprite。

“设置”的两种状态均已修正为笔画完整的简体黑体字形，请使用文件名带 v2 的图片。此前版本保留在旧版文件夹，字体修正记录.json 保存了本次提示词与来源。

使用 UI Button 的 Sprite Swap：Source Image 放未选中图；Highlighted Sprite 和 Selected Sprite 放青蓝色选中图。Pressed 可先沿用选中图。暂停、继续、返回主菜单和打开设置的逻辑由 Unity 按钮事件连接。

本次由内置 image_gen 逐张绘制，沿用主菜单参考图的造型与配色，保留生成的透明通道。详细提示词与素材来源分别见绘制提示词.txt 和素材清单.json。
