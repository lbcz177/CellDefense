# 设置界面独立文字素材 v1

2026-10-19。根据本轮开始时 `GameSettingsPanel` 的实际文案，用内置 image_gen 独立绘制十份位图字样，Aseprite 统一透明边缘、最近邻尺寸和基线。沿用奶油金色字面、深紫色轮廓，方便与现有暂停面板、声音图标和拉条搭配。

主要字样和百分号的字形高度为 64，距画布顶部的基线为 72；三条提示文字的字形高度为 32、基线为 40。每份 PNG 都只有文字，四边透明，不含按钮背景、面板或图标。“静音”同时提供为独立通用标签，即使当前页面主要通过喇叭图标切换静音，也可用于后续排版。

## 数字、预览和源文件

音量数字沿用 `战斗UI/ATP像素数值_v1/数字/0.png` 至 `9.png`；新的百分号与它们保持相同字形高度和基线，可自由组合 0% 至 100%。

- `设置文字_预览.png`：十份字样总览，另用已有数字组合 65% 示例，深底仅供展示。
- `设置文字_透明总览.png`：十份文字的透明排版总览。
- `设置文字_分层源文件.aseprite`：十个独立命名图层，可逐项修改。

## Unity 使用

PNG 已配置为 Sprite Single、Point、Full Rect、无压缩、不生成 Mip Maps、中心锚点。可用 UI Image 显示对应字样，保持长宽比；按钮背景与文字 Image 分开，使背景选中状态不影响文字的位置。建议按原尺寸或整数比例缩放以保持像素边缘清楚。

本轮交付为位图文字素材，未制作 TTF/TMP Font Asset，也未修改当前设置页文字绑定或任何游戏逻辑。声音与拉条的图片在相邻 `设置界面_声音与拉条_v1` 文件夹。

## 检查与来源

已人工查看十份原稿和最终缩放总览中的文字、标点；Aseprite 检查透明四边、主要字形和提示字形的统一高度与基线、PNG 重载一致、原生分层文件重开一致。尺寸与透明角落另行检查通过。

原稿、最终提示词、导出脚本、文案清单与检查报告位于 `制作记录~/`。提示词为 `制作记录~/提示词.md`，报告为 `制作记录~/validation.json`。本轮未运行 Unity 原生验证，旧素材及其 meta 保留。
