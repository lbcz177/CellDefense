# 六塔与普通敌人：强化动画 v2

本次补齐 11 组动画：其余五塔的攻击、三种普通敌人的移动与攻击。之前完成的中性粒细胞新版位于相邻的 `中性粒细胞_强化攻击_v2/`，并参与塔攻击总览。

## 总览动图

- `塔攻击总览.gif`：三列两行。第一行从左到右为中性粒细胞、纤维蛋白、溶酶体；第二行为神经塔、巨噬细胞、抗体 B 细胞。
- `敌人移动与攻击总览.gif`：两列三行。左列移动、右列攻击；从上到下为葡萄球菌群、鞭毛双球菌、重甲芽孢杆菌。
- 同名 PNG 为总览首帧，只用于静态预览。

## Unity 使用

序列图已配置 Sprite Multiple、八个预切片、中心 Pivot、128 PPU、Point，关闭纹理压缩和 Mip Maps。独立帧使用 Sprite Single。

攻击预览每轮 1 秒，帧时长依次为 160、90、60、50、70、90、130、350 毫秒。第 4 帧为释放/接触姿势，起始时间为 310 毫秒；游戏内应每次攻击播放一次，发射或伤害事件与该姿势对齐。末尾采用首帧待机姿势，留出观察停顿。

移动动画八帧均为 100 毫秒，每轮 0.8 秒；各帧保留连续运动阶段。移动序列表现原地动作，敌人在地图中的位移仍由游戏逻辑控制。

普通等间隔 Unity AnimationClip 不会自动读取 GIF/JSON 的非等时帧时长，需要按 `animation.json` 配置关键帧时间。素材已导入项目目录，本次未修改 Animator、Prefab、战斗参数或现有资源引用。

## 制作与检查

关键帧由内置 image_gen 绘制，Aseprite 完成最近邻缩放、身体/根部对齐、帧时长设置及 GIF 导出。所有 PNG 保留透明背景。

已检查：八帧数量、128×128 单帧尺寸、512×256 序列图尺寸、边缘透明留白、独立帧与源文件/序列图一致、攻击首尾衔接、GIF 循环及各帧时长。

完整提示词、生成记录、原始关键帧、制作脚本及验证报告位于 `Docs/Art/AnimationSamples/CoreUnits-Strong-v2/`。`jobs.json` 保存原始提示词，`progress.json` 另包含神经塔受体数量修正的提示词及最终资源路径。
