# 葡萄球菌群圆形俯视修正 v4

2026-10-16。旧菌群中的单个细胞呈椭圆，整体偏宽，并带有斜视感；绕 Z 轴朝下后，容易显得整簇侧立。内置 image_gen 重绘为一颗中央球菌加六颗外围球菌的近圆形正俯视菌群，Aseprite 统一锚点、透明像素边缘、最近邻尺寸与帧时长。

## 本轮效果

- 细胞由扁椭圆改为圆形，保留紫红色、深紫轮廓、少量黄绿色内容物的识别特征。
- 移动时由细胞之间的轻微挤压、起伏表现活动，整体仍接近圆形。
- 保留主体跟随方向平面旋转、绝不镜像的方式；没有锁死朝向。
- 移动十帧、一秒循环；攻击十帧、480 毫秒，原事件时间保持不变。
- 静止主体最大尺寸约 80 像素，原图约 81 像素；沿用原有 PPU 和 Prefab 缩放，避免单位突然变大。

## 资源与实际接入

本目录 `07_staph_move` 与 `07_staph_attack` 各提供透明 640×256 图集（5×2，单格 128×128）、十张独立帧、原生 Aseprite、JSON 帧信息与 GIF。

这两套图像同步更新到原有关卡引用的 `正俯视10帧_v3/07_staph_move` 和 `07_staph_attack` 中，保留旧文件的 meta、Sprite 切片 ID、AnimatorController、AnimationClip、Prefab 和碰撞参数。未重建场景或修改数值与寻路逻辑。

替换前的图片、源文件、帧信息、预览和 meta 保存在 `制作记录~/backup/`，并保留原 Prefab 及两段 AnimationClip 作为引用核对依据。

## 检查

Aseprite 已验证每个动作十帧图像不同、透明边缘、稳定锚点、图集与独立帧一致、原生文件重开一致。四方向预览只做 90 度平面旋转，不镜像。移动轮廓最大长宽比由约 1.42 降为约 1.08，减少方向变化引起的扁长观感。

检查报告、最终提示词、原始生成稿、导出与方向检查脚本都在 `制作记录~/`。Unity 原生导入检查日志为 `unity-validation.log`；本轮没有进入 Play 进行完整关卡实测。

Unity 原生导入与既有 22 段动作引用检查通过，批处理退出码 0。原有 PNG meta 逐字节未变；Aseprite 导入器按新轮廓自动更新打包坐标，其原 GUID 和 Sprite ID 保留。原葡萄球菌 Prefab 与移动、攻击 AnimationClip 文件未变。
