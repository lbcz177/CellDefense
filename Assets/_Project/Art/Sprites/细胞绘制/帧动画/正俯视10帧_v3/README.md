# 正俯视十帧动画 v3

2026-10-16。内置 image_gen 重绘动作，Aseprite 统一主体锚点、最近邻缩放、透明边缘与帧时长；Unity 2022.3.53f1c1 原生导入与绑定。

共六座塔和当前八类敌人，22 段动作、220 张不同动作帧。素材采用正俯视外观，原始动作统一朝右。运行时，敌人主体沿实际移动方向绕 Z 轴旋转，接敌时朝向防御塔；塔主体面向攻击目标。全程不镜像、不通过负缩放转向。

## 总览

- 六塔攻击总览.gif：三列两行，第一行中性粒细胞、纤维蛋白、酸化炮；第二行神经塔、巨噬细胞、B 细胞。
- 八类敌人移动与攻击总览.gif：四列四行，每种敌人的左格移动、右格攻击。第一行葡萄球菌、双球菌；第二行重甲杆菌、孢子；第三行复制体、真菌 Boss；第四行生物膜 Boss、病毒母体。

总览中的攻击每秒循环一次，并在动作后增加观察停顿；独立 preview.gif 保留实际动作时长。深色背景只用于 GIF 预览。

## 独立资源与 Unity 切片

每个“单位_动作”目录各含 animation_sheet.png、animation.aseprite、preview.gif、animation.json，以及 frames/frame_01.png 至 frame_10.png。序列图均为透明 640×256，5 列×2 行、每格 128×128，从左到右、从上到下共十帧，Pivot 为中心。原生图集已设置 Sprite Multiple、十个预切片、Point、无压缩和无 Mip Maps；PPU 按各 Prefab 的既有根缩放校准，未改变碰撞体与根缩放。

移动每帧 100 毫秒，完整循环一秒。攻击十帧依次 50/40/40/30/40/40/50/50/60/80 毫秒，完整动作 480 毫秒；第 5 帧在 160 毫秒进入释放/接触阶段。没有使用插入重复帧来凑十帧，每段均检查十帧图像不同。

## 已接入现有游戏单位

新原生 AnimationClip、AnimatorController 和状态材质位于 Assets/_Project/Art/Animations/TopDown10_v3。六个现有塔 Prefab 与八个现有敌人 Prefab 已连接新资源，原 Prefab 及其 meta GUID 保留。旧八帧图片、控制器及旧敌人模板仍保留。

塔在准备及释放时对准目标，在释放帧调用已有 ReleaseAttack，主体不再 flipX/flipY。发射点先把目标方向转换回主体本地空间，避免重复旋转。敌人在移动位移发生后更新朝向，在最后一段移动后才开始核心攻击；每次出生或召唤都会按新路线初始化朝向。纤维蛋白沿用唯一壁垒与被动行为，以循环活跃脉冲表现十帧，不增加主动攻击或伤害。敌人近战前播放准备动作，伤害仍由原接敌间隔结算；离开接敌后恢复移动。到核心后的完成事件在 460 毫秒触发，让恢复帧可见；超时保护仍在。暂停沿用游戏时间。

受盾、破甲、减速、可吞噬提示和 Boss 阶段不再覆盖为旧斜视静态图，改用动画上的状态颜色，并保留已有状态条、标记和能力脉冲。旧状态图不删除。
