# 生命、波次与三栏 HUD 框

2026-10-16。内置 image_gen 分别绘制六份图形，Aseprite 裁切、最近邻缩放、透明边缘整理并导出。画风与现有 ATP 数字、下一波按钮一致：奶油金字样、深紫描边、珊瑚粉边缘。最终提示词、原稿、导出脚本与检查报告保存在 `制作记录~/`。

## 排版与 Unity 导入

PNG 已配置 Sprite Single、Point、不压缩、不生成 Mip Maps、中心锚点。空框可以作为 UI Image 背景；图标、字样和数字各用独立 Image 叠放，实时更新数字即可。建议保持长宽比并按整数倍缩放，整个空框使用 Simple 模式；内部分栏不适合直接做九宫格拉伸。

组合参考中图标按原图 0.5 倍（64×64）显示；字样与数值按原图 0.5 倍显示，字形高度均为 32。示例坐标与尺寸记录在 `制作记录~/validation.json` 的 previewRects 中，坐标原点为图片左上角。示例数值仅用于排版参考。

`HUD三栏空框.aseprite` 是空框源文件；`生命波次素材.aseprite` 中字样、图标和斜杠各占独立图层；`HUD组合参考.aseprite` 中底框、所有图标、字样及每个示例数字均分层，可直接调整布局。

## 检查范围

已人工检查“生命”“波次”、爱心、敌群与斜杠方向；Aseprite 验证六张素材四边透明、字样与斜杠高度及基线一致、独立 PNG 重载一致、原生源文件重开一致。已查看组合预览，确认内容位于三个独立区域内。未修改现有关卡 HUD 或数值逻辑，未启动 Unity 运行验证。
