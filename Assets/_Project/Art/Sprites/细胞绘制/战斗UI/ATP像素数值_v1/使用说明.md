# ATP 像素数值素材

用于《胞卫战》HUD 的位图字样、数字与 ATP 资源标识。内置 image_gen 分别绘制三份原稿，Aseprite 裁切、最近邻缩放、统一基线并导出，2026-10-16。

## 素材

- `ATP字样.png`：192×80，独立透明「ATP」字样。
- `ATP标识.png`：128×128，三个金黄颗粒和青色连接的独立资源标识。
- `数字/0.png` 至 `数字/9.png`：每张 64×80，透明背景，字形高度 64、基线距顶部 72，十个数字可自由组合数值。
- `数字图集_5x2.png`：320×160，上排 0–4、下排 5–9。Unity Sprite Multiple 已配置十个 64×80 切片，名称 `digit_0` 至 `digit_9`。
- `ATP像素数字.aseprite`：数字图集的可编辑源文件，每个数字一个命名图层。
- `ATP字样与标识.aseprite`：字样与资源标识的可编辑源文件，各自独立图层。
- `展示预览.png`：ATP 1250 组合及十个数字的排版参考；深色底仅供预览。

## Unity 使用

PNG 均配置为 Sprite、Point、无压缩、不生成 Mip Maps、中心锚点。使用 UI Image 分别显示图标和 ATP 字样；数值可使用十个独立数字 Sprite，或图集中的十个切片。统一按 64×80 的格子大小排版，可以保持数值更新时位置稳定。保持图片长宽比，建议按整数倍缩放以保留清晰像素边缘。

当前交付为位图字体素材，尚未创建 TMP Font/Sprite Asset，也未修改现有关卡 HUD、字体资源或 ATP 数值逻辑。Unity 正在运行，已写入素材及导入配置，未启动另一份 Unity 进行原生导入验证。

Aseprite 已验证十个数字内容不同、字形高度与基线一致、透明边缘、原生源文件重开一致、图集与独立图片一致；人工检查了 ATP 字母、数字 0–9、图标与组合预览。原稿、最终提示词、导出脚本和检查结果在 `制作记录~/`，该目录不参与 Unity 素材导入。原有 ATP 图标及其 meta 保留。
