## Aseprite

Aseprite源文件/ 下有暂停、正常速度_1x、双倍速度_2x 三份 .aseprite。每份两层：按钮底板、符号；第1帧 Normal、第2帧 Selected。两帧表示按钮状态，不需要作为动画自动播放。六态展示.aseprite 是六张成品的分层排版预览。按钮展示预览.png 使用深紫展示底色，该底色不在六张成品中。

## Unity 使用建议

- 导入为 Sprite (2D and UI) / Single；Point (no filter)，无压缩、无 Mip Maps，Pivot 中心。
- UI Image 保持 2:1 比例，颜色设为白；宜使用 128×64 原生尺寸或整数倍。避免直接拉成旧工具条 100×36 的比例。
- 暂停按钮使用常态图；Highlighted / Pressed 指定高亮图，可继续调用已有 Pause。
- 倍速按钮按当前 PlaybackSpeed 显示 1× 或 2×；对应高亮图用于鼠标悬停 / 按下。原有 TogglePlaybackSpeed 控制速度。
- 暂停时沿用现有不可交互逻辑。美术未改变暂停、时间倍率、场景与配置。
