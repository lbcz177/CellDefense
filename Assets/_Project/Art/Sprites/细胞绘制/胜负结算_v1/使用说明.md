# 胞卫战 · 胜负结算 v1

本批共 8 张独立透明 PNG：胜利、失败面板各一张，三个按钮各含未选中和选中状态。界面与按钮完全分开，面板上只有标题、细胞装饰与空白内容区。

| 失败面板，无按钮 | 02_失败界面_无按钮.png |
| 下一关，未选中 / 选中 | 03_下一关_未选中.png / 04_下一关_选中.png |
| 重新挑战，未选中 / 选中 | 05_重新挑战_未选中.png / 06_重新挑战_选中.png |
| 返回主菜单，未选中 / 选中 | 07_返回主菜单_未选中.png / 08_返回主菜单_选中.png |

建议胜利界面放置“下一关、重新挑战、返回主菜单”；最后一关隐藏“下一关”。失败界面放置“重新挑战、返回主菜单”。按钮可在两个面板之间复用。

面板内部不含分数、奖励、星级等固定数值，可由 Unity UI 在留白区域叠加动态文字。标题“胜利／失败”已包含在面板 PNG 中，按钮文字也已包含在各按钮 PNG 中，不需要再覆盖同样的文字。

Unity 使用建议：Texture Type 选 Sprite (2D and UI)，Sprite Mode 选 Single。像素风显示可使用 Point 过滤并关闭压缩。面板用 Image 的 Preserve Aspect 保持比例；按钮使用固定 RectTransform，Normal 状态显示奶油色图片，Highlighted / Selected 使用对应青蓝色图片。按钮文字已画入素材，不建议直接通过九宫格拉伸。

素材已按用户指定放在项目的 Art/细胞绘制分类目录。本次只制作并导入美术素材，场景中的按钮摆放和点击逻辑尚未接入。

制作方法：内置 image_gen 分别生成，每张图保持独立，保留原始透明通道。参考来源与完整提示词见素材清单.json、绘制提示词.txt；文件尺寸与 SHA-256 见图片检查.json。
