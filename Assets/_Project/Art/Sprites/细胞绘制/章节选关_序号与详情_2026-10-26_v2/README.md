# 序号选关与点击详情 v2

按用户最新要求，将选关页改为仅显示章节内关卡序号和最佳星级；点击序号才显示地图、关卡名、历史最高通关分及最佳星级，再由“开始游戏”进入。

第一章为 1—5，第二、三章按当前四关策划为 1—4。三个序号页都不展示缩略图、关卡名或分数；编号、按钮、星级和背景独立，可按新关数增加、重排或分页。选章页沿用 v1。

`完整界面/` 包含三张序号页、三个章节的点击后详情示意，以及一个未通关详情状态。完整 PNG 均为 1600×900，各有 `源文件/` 下的同名 Aseprite。示意中的 9600 分为美术演示数据，运行时只读取实际存档，不写入演示分数。

`组件/` 提供常态／高亮序号按钮、详情底板和常态／高亮操作按钮；`文字/` 提供 1—5 的独立大字、历史最高分／最佳星级标签、操作按钮文字和全部关卡详情标题。保留 v1 素材及其 `.meta`，这次使用 Aseprite 调整已有图层与组件，没有重新调用图像生成模型。

现有五个可玩场景已使用新的两步选关：数字按钮只打开模态详情，地图完整等比显示；分数按 `LevelProgress.BestScore` 读取，未通关显示“未通关”，空记录不伪装为零分。详情每次打开重新取值，返回与 Esc 恢复到对应数字按钮，底层页面在详情打开时禁止鼠标与键盘操作。

历史数据仍为已有的最高通关分和由其计算的最佳星级，没有新增逐局历史、修改评分、引入解锁门槛或更换存档键。第二、三章保留美术与素材索引，尚未新增可玩关卡。`可扩展素材索引.json` 说明了当前章节资源与交互层次。

制作计划、字体来源、接入前备份、美术检查及验证记录保存在 `制作记录~/`。交互实现位于主菜单控制器，`LevelSelectionArtwork` 集中引用共用组件；动态数字继续由现有像素字图绘制。
