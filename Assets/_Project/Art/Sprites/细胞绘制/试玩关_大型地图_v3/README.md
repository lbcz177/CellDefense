# 试玩关大型地图 v3

三张独立的完整地图，延续中央核心、底部左右两个伤口入口和暖粉色卡通像素风。通过缩小核心和环境细节在画面中的占比，增加可见场地面积和布塔空间。

| 文件 | 布局 |
| --- | --- |
| 01_大型地图_错位组织岛.png | 五块错位组织岛，开放式绕行，中央空地宽敞 |
| 02_大型地图_分段组织屏障.png | 五段分离的组织障碍，下半区形成轻度折返 |
| 03_大型地图_宽阔回廊.png | 下方弧形屏障与两侧组织段分离，保留宽阔侧向通道；上方有一小块组织岛 |

图片保持生成工具输出的原生分辨率。新 Sprite 的 PPU 设置为图片宽度 / 24，在 Transform Scale = (1,1,1) 下显示为 24×18 Unity 单位；这比此前地图约 14.64×10.74 单位的显示范围更大。

导入参数：Sprite / Single、Point、关闭 Mip Maps、Compression None、Full Rect。每个场景一张 PNG。

本批是完整美术布局图，核心和组织障碍均在背景中。游戏场景的网格尺寸、出生点、碰撞与寻路配置尚未按新图调整。

使用内置 image_gen，以 v2 绕路地图为画风参考生成。完整提示词与参考信息保存在 `制作记录~/prompts.json`，实际尺寸、导入比例和校验信息见 `制作记录~/manifest.json`。
