# 细胞徽章关卡序号 v3

按用户“12345 设计得有风格一点”的反馈，将原方框加普通数字改为一套组织膜细胞徽章：奶油色立体数字、墨紫轮廓、珊瑚下缘阴影、浅色胶原膜和少量细胞颗粒。保持五个数字同一套材质、大小与视觉层次。

`徽章/` 中有 1—5 的常态与选中态，并附空白扩展徽章，共十二张 256×256 透明 PNG。选中态只增加青色外缘，数字和组织图形逐像素保持一致。`源文件/` 附六份徽章 Aseprite：常态基底与可关闭的选中描边分层保存。

`完整界面/` 更新第一、二、三章的序号页，每张图有对应 Aseprite。三章仍分别为 5／4／4 关，星级独立显示；地图和历史最高分继续仅在点击后的详情中显示。`五枚徽章_常态与选中.png` 为两种状态近览，`细胞徽章选关总览.png` 包含三章与近览。

使用内置 image_gen 绘制统一的 3×2 原始徽章图集，再以 Aseprite 拆分、清理透明光晕、等比归一和绘制选中边缘。原始图、完整提示词、输出哈希、拆分计划和制作脚本在 `制作记录~/`。既有 v1／v2 素材与 `.meta` 保留。

现有五关使用独立数字徽章，隐藏叠加的普通数字，避免重影。`LevelSelectionArtwork` 逐关引用常态与选中图，保持原资源资产 GUID；第 6 关及以后没有专用图片时，回退为空白徽章加动态字图。位图徽章按完整比例显示，不使用九宫格拉伸。`可扩展素材索引.json` 给出数字与图片映射。

本次只调整序号美术及其资源选择，不修改关卡数量、成绩记录、评分规则、地图、详情或开始游戏流程。第二、三章仍为美术储备，未新增可玩场景。
