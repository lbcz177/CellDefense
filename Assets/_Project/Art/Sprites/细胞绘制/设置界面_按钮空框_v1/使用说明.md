# 设置界面：恢复默认与返回按钮空框

四张透明 PNG 分别对应两个按钮的普通状态和蓝色选中状态，文字不包含在空框中；两个按钮使用统一外形。

- 01_恢复默认_空框_未选中.png
- 02_恢复默认_空框_蓝色选中.png
- 03_返回_空框_未选中.png
- 04_返回_空框_蓝色选中.png

每张 448×80，框体 432×64，四周透明留白 8 像素。两种状态尺寸与位置一致。Unity 导入为 Single Sprite、Point、Full Rect、不压缩、无 Mipmap；九宫格边界为左 56、下 24、右 56、上 24。需要调整尺寸时可使用 Image Type = Sliced；选中状态可通过 Sprite Swap 切换。

叠加文字请使用相邻目录“设置界面_文字素材_v1”的 05_恢复默认.png 与 06_返回.png。组合预览使用文字原尺寸的 50%，居中叠放。

“按钮空框_预览.png”仅展示四个空框；“恢复默认与返回_组合预览.png”仅供查看文字叠放效果，均不作为实际按钮素材。“恢复默认与返回_按钮框.aseprite”为可编辑空框源文件；“恢复默认与返回_组合参考.aseprite”为分层组合参考。

使用内置图像生成工具绘制，再通过 Aseprite 进行透明裁切、尺寸整理、空白中段延展与导出。提示词、原始生成图、打包脚本和验证记录位于“制作记录~”。已检查四张图尺寸、透明背景、两种状态对齐及 Aseprite 源文件。原有素材保留，本次仅新增美术资源，未修改场景与运行代码。
