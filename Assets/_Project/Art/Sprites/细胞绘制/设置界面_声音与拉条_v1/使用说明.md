## 预览和源文件

- `声音与拉条_预览.png`：上下分别展示声音开启、静音图标；两行示例都保留 65% 的滑块值，与静音保留音量设置的行为一致。深底仅用于查看。
- `声音与拉条_组合透明.png`：单行透明排版参考，示例音量 65%。
- `声音与拉条_分层源文件.aseprite`：声音图标、静音图标、底槽、完整填充、65% 参考填充和滑块独立图层，方便继续编辑。

## Unity 导入和组装

PNG 已配置 Sprite Single、Point、Full Rect、无压缩、无 Mip Maps、中心锚点。底槽的 Border 配置为左右 24、上下 16，可在 UI Image 中使用 Sliced 延长槽体。

UGUI Slider 中，Background 使用底槽图；Fill 使用蓝色填充图；Handle 使用拖动柄图，并分别配置 fillRect、handleRect、targetGraphic。声音/静音图标用另一个独立 Image 切换。尺寸、透明边距和示例摆放坐标见 `制作记录~/validation.json`，均使用图片左上角坐标。

本轮交付图片与导入配置，尚未替换 GameSettingsPanel 里动态生成的控件，也未修改设置、音量或静音逻辑。
